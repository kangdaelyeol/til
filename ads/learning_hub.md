## MAIBA (Meta AI Business Assistant)

Ads Manager, Meta Business Suite, Business Support Home에 내장된 대화형 AI 어시스턴트이다.

**`진입점`**

Analysis 로고 또는 Ask Meta AI 클릭 (강의 화면 기준, UI는 변경될 수 있음)

### 핵심기능

**`ROAS 트렌드 및 업계 벤치마크 비교`**

내 계정의 ROAS 등 성과를 같은 업종의 익명화된 광고주 집단과 비교하는 기능 제공

비교 집단에 어떤 광고주가 포함되는지는 공개되지 않음

단, 업종은 메타 시스템에 의해 자동선택되어 임의로 업종 선택 불가

**`예산, 타겟, 데이터 설정 최적화`**

MAIBA는 검토 및 제안만 제공하고 캠페인을 직접 변경하지 않음

최종 판단과 실행은 광고주가 직접 진행 또는 어카운트 매니저 상담

제안은 Opportunity Score(기회 점수) 추천과 연결됨

- Meta 발표: 추천 적용 시 전환당 비용 12% 감소 (Meta 자체 발표 수치)

**`계정 지원`**

계정 문제의 원인 파악 및 해결을 돕는 기능 제공, 해결되지 않으면 상담원과 소통 진행

### 효율적인 답변을 위한 질문 방법

**`구체적으로 질문하기`**

대상(캠페인), 기간, 지표를 명시

**`후속질문`**

한 번에 끝내지 않고 답변을 바탕으로 질문을 계속 이어가기

- ex) "그중 영향이 가장 큰 원인은 뭐지?" 이후 "그 부분은 어떻게 개선할 수 있지?"

**`맥락 공유`**

비즈니스 목표, 예산, 최근 변경 사항 등 배경 정보를 함께 전달

**`진단 + 해결책 요청`**

현재 상황(진단)을 설명한 뒤 "어떻게 할까요" 식으로 조치 방안까지 요청

## 머신러닝 + 캠패인 구조

### 머신러닝 최적화

적절한 **시점(When)** 에 적절한 **사람(Who)** 에게 적절한 **광고(What)** 를 보여주는 것을 최적화라고 정의

### 광고학습

광고 학습은 **광고세트(Adset)** 단위로 진행한다

7일 이내에 50개의 전환(최적화) 이벤트가 확보되면 학습을 종료한다

**`광고학습 최적화 방안`**

| 방안              | 설명                                                             |
| ----------------- | ---------------------------------------------------------------- |
| 잦은 수정 피하기  | 중요한 광고셋 수정(Significant Edit)은 학습을 초기 상태로 되돌림 |
| 제한사항 덜어내기 | 타겟 확장, 노출 지면 확장, 예산 등 범위를 넓게 할 것을 권장      |
| 광고셋 통합       | 지나치게 세분화된 광고셋은 통합하는 것을 권장                    |

### 캠페인 구조의 정석

**`하나의 캠페인 + 하나의 광고셋(Adset) + 여러소재`**

하나의 켐페인에서 세분화된 광고셋 설정보다는 하나의 광고셋에 여러 소재를 두어 통합하는 것을 권장한다

**`고객 세그먼트 통합`**

모든 고객 세그먼트를 타겟하는 단일 광고셋트로 설계하는 것을 권장한다

고객 세그먼트를 세분화하여 각각의 캠페인 또는 애드셋에 설정할 경우 예외상황이 발생할 수 있다

| 예외상황                     | 설명                                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 경매중복(Auction Overlap)    | 세그먼트마다 중복 고객이 존재할 수 있다. 따라서 여러 광고셋이 같은 고객을 두고 입찰하는 구조가 발생할 수 있다 |
| 오디언스 분산(Fragmentation) | 오디언스를 지역, 연령단위로 세분화 하면, 오디언스 풀이 부족하여 학습에 필요한 데이터를 수집하기 어려움        |

- **Auction Overlap** : 중복된 광고셋이 서로 입찰가를 올려 광고비가 과지출 되는 매커니즘이 아님, 총 가치가 높은 하나의 광고셋만 경매에 내보내고, 나머지 중복된 광고셋은 경매에서 제외함. 따라서 나머지 광고셋이 학습단계를 벗어나지 못할 수 있다.

### 광고셋트 통합 기준과 방법

동일한 소재와 목표의 경우

광고 관리자(ads manager)페이지에서 알려주는 추천(Recommendation) 확인

- 추천(Delivery Recommendations)에 경매 중복 시 광고 세트 통합 제안이 뜬다

정확한 광고셋 통합 기준 확인을 위해 어카운트 매니저 직접 문의
