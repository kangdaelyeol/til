## 빅데이터의 이해

### 빅데이터의 정의

빅데이터는 측면에 따라 여러 의미로 정의된다.

| 주체                           | 정의                                                                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 일반적 정의                    | 기존 데이터베이스 관리도구로는 수집·저장·관리·분석하기 어려운 규모의 정형 및 비정형 데이터를 포함하여, 이로부터 가치를 추출하고 결과를 분석하는 기술 |
| 매킨지(Mckinsey) 정의          | 일반적인 데이터베이스 소프트웨어가 저장·관리·분석할 수 있는 범위를 초과하는 규모의 데이터로, 데이터 규모 자체에 초점을 둔 정의                       |
| IDC 정의                       | 다양한 종류의 대규모 데이터로부터 저렴한 비용으로 가치를 추출하고, 초고속의 수집·발굴·분석을 지원하도록 고안된 차세대 기술 및 아키텍처               |
| 더그 래니(Doug Laney)정의 - 3V | 규모(Volume)·다양성(Variety)·속도(Velocity)의 3가지 측면에서 급격히 증가하는 데이터                                                                  |
| 마이어쇤버거와 쿠키어의 정의   | 표본조사가 아닌 전체 데이터(N=all)를 대상으로 분석함으로써, 기존 방식으로는 어려웠던 상관관계와 통찰을 도출할 수 있게 하는 데이터                    |

### 빅데이터의 특징 - 3V / 4V

**`더그 래니의 3V`**

가트너 그룹의 부회장인 더그 래니(Doug Laney)는 빅데이터를 3V의 증가로 요약하였다.

| 구분     | 설명                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| Volume   | 저장 매체 가격 하락과 기술 발전에 따라 폭발적으로 증가하는 데이터의 규모                     |
| Variety  | 정형 데이터뿐 아니라 텍스트, 이미지, 로그 등 반정형·비정형 데이터까지 포함하는 형태의 다양성 |
| Velocity | 데이터가 생성·수집·처리·분석되는 속도가 실시간에 가깝게 빨라지는 특성                        |

**`빅데이터의 새로운 특징 - 4V`**

Doug Laney의 3V 특징의 추가로 특징을 두어 4V로 빅데이터의 특징을 설명하기도 한다. 추가 특징은 다양하게 해석된다.

| 구분                | 설명                                                                      |
| ------------------- | ------------------------------------------------------------------------- |
| Value               | 다양한 분석을 통해 새로운 가치를 창출할 수 있어야 한다는 특성             |
| Veracity(정확성)    | 데이터의 신뢰성과 품질을 확보하여 분석 결과의 정확성을 보장해야 하는 특성 |
| Visualization       | 방대하고 복잡한 데이터를 이해하기 쉽도록 시각적으로 표현하는 특성         |
| Variability(가변성) | 동일한 데이터라도 상황·문맥에 따라 의미와 가치가 달라지는 특성            |

### 빅데이터 출현 배경

빅데이터는 새롭게 등장한 개념으로 보는 것이 아닌, 기술의 패러다임 이전 현상으로 바라봐야 한다.

**`산업계의 변화`**

산업계에서 일어난 빅데이터 현상을 **양질 전환의 법칙** 으로 설명하기도 한다.

- 양질 전환의 법칙은 헤겔의 변증법에 기초를 둔 개념으로, 양적인 변화가 축적되면 질적인 변화도 이루어진다는 개념이다.

양질 전환의 법칙은 정보가 지속적으로 축적되면서 거대한 데이터는 새로운 기술을 만나 새로운 가치를 창출할 수 있는 변화의 상태가 된다고 설명한다.

**`관련 기술의 발전 - 클라우드 컴퓨팅`**

클라우드 컴퓨팅은 대용량의 데이터를 병렬 분산처리 시스템으로 처리할 경우 비용이 혁신적으로 줄어든다는 특징이 있으며, 이는 빅데이터를 분석하고 새로운 가치를 창출하는 데 기여했다고 볼 수 있다.

### 빅데이터의 비유적 특징

| 비유                | 설명                                                                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 산업혁명의 석탄, 철 | 산업혁명 시기의 석탄·철처럼 다른 산업, 정부 정책, 개인의 삶 전반에 융합되어 사회 전반에 혁명적 변화를 가져올 것으로 기대                 |
| 21세기 원유         | 원유가 정제를 거쳐 다양한 제품으로 활용되듯, 빅데이터도 분석·가공을 거쳐 여러 산업에서 새로운 가치를 창출하는 핵심 자원이 될 것으로 기대 |
| 렌즈                | 현미경이 세포를 관찰하게 하여 생물학 발전을 이끌었듯이, 빅데이터는 사회의 변화를 관찰하고 대응하게 하는 렌즈 역할을 할 것으로 기대       |
| 플랫폼              | 플랫폼처럼 여러 주체가 공동으로 활용할 수 있는 기반이 되어, 다양한 서드파티 비즈니스에 활용될 것으로 기대                                |

### 빅데이터가 만들어내는 변화

| 구분                 | 설명                                                                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 사전처리 -> 사후처리 | 목적에 맞게 데이터를 미리 정제해 저장하던 방식에서, 일단 대량의 데이터를 모두 저장한 후 필요할 때 사후적으로 가공·분석하는 방식으로 변화 |
| 표본조사 -> 전수조사 | 제한된 표본을 추출해 분석하던 방식에서, 모든 데이터(N=all)를 대상으로 분석하는 방식으로 변화                                             |
| 질 -> 양             | 데이터의 정확성(질)보다 확보한 데이터의 양이 더 유의미한 결과를 가져온다는 관점으로 변화                                                 |
| 인과관계 -> 상관관계 | 왜(Why) 발생했는지의 인과관계 규명보다, 무엇(What)이 함께 발생하는지의 상관관계 파악을 중시하는 방향으로 변화                            |

## 빅데이터의 가치와 영향

### 빅데이터의 가치

**`인사이트 발굴`**

빅데이터의 가치는 인사이트를 발굴하여 어떻게 활용하는지에 따라 결정된다.

**`빅데이터 가치 산정의 어려움`**

| 구분             | 설명                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 데이터 활용 방식 | 데이터가 언제, 어디서, 누구에 의해 어떤 목적으로 활용될지 예측할 수 없어, 사용 전에 가치를 산정하기 어려움                                    |
| 가치 창출 방식   | 데이터를 다른 데이터와 재조합하거나 새로운 방식으로 결합해 기존에 없던 가치를 창출할 수 있어, 가치를 미리 가늠하기 어려움                     |
| 분석 기술의 발전 | 현재 기술로는 분석이 어려운 데이터도 향후 기술 발전에 따라 분석이 가능해져 새로운 가치가 발생할 수 있어, 지금 시점에서 가치를 예측하기 어려움 |

## 빅데이터 활용 기본 테크닉

### 연관 규칙 학습(Association rule learning)

**`설명`**

하나의 거래나 사건에 포함된 항목들 간의 상관관계를 찾아내는 기법이다.

**`특징`**

if-then 형태의 규칙으로 표현되며, 지지도(Support)·신뢰도(Confidence)·향상도(Lift) 등의 지표로 규칙의 유용성을 평가한다.

**`활용 예`**

장바구니 분석(맥주와 기저귀를 함께 구매하는 경향 파악), 상품 추천, 교차 판매

### 유형 분석(Classification / Clustering tree analysis)

**`설명`**

새로운 데이터를 미리 정의된 범주에 할당(분류)하거나, 유사한 데이터끼리 그룹화(군집화)하는 기법이다.

**`특징`**

분류는 정답(레이블)이 있는 지도학습, 군집화는 정답 없이 유사도를 기반으로 그룹화하는 비지도학습에 해당한다. 대표 알고리즘으로 의사결정나무, K-means 등이 있다.

**`활용 예`**

고객 세분화, 스팸메일 분류, 신용등급 분류

### 유전 알고리즘(Genetic algorithms)

**`설명`**

생물의 진화 과정(선택, 교배, 돌연변이)을 모방하여 최적의 해를 탐색하는 최적화 알고리즘이다.

**`특징`**

세대를 거듭하며 우수한 해를 선택·교차·돌연변이시켜 점진적으로 최적해에 근접해간다.

**`활용 예`**

최적 일정 계획, 최적 경로 탐색, 포트폴리오 최적화

### 머신러닝

**`설명`**

컴퓨터가 데이터를 학습하여 스스로 패턴을 찾아내고 예측·분류 등을 수행할 수 있도록 하는 인공지능의 한 분야이다.

**`특징`**

명시적인 프로그래밍 없이 데이터(경험)를 통해 성능을 향상시키며, 지도학습·비지도학습·강화학습 등으로 구분된다.

**`활용 예`**

이미지 인식, 음성 인식, 추천 시스템, 이상 탐지

### 회귀분석(Regression analysis)

**`설명`**

독립변수(원인)와 종속변수(결과) 간의 관계를 수학적 모형(함수식)으로 나타내어 값을 예측하는 통계 기법이다.

**`특징`**

변수 간 관계의 통계적 유의성을 검정할 수 있으며, 단순회귀분석과 다중회귀분석 등으로 구분된다.

**`활용 예`**

매출 예측, 주택 가격 예측, 광고비 대비 판매량 분석

### 감정분석(Sentiment analysis)

**`설명`**

텍스트에 나타난 사람들의 의견, 감정, 태도(긍정/부정/중립 등)를 분석하는 텍스트 마이닝 기법이다.

**`특징`**

자연어처리(NLP) 기술을 활용하며, SNS·리뷰 등 비정형 텍스트 데이터에 주로 적용된다.

**`활용 예`**

상품 리뷰 분석, 브랜드 평판 모니터링, 여론 분석

### SNS분석(Social Network analysis)

**`설명`**

소셜 네트워크상의 개체(노드)들과 그들 간의 관계(링크)의 패턴과 강도를 분석하는 기법이다.

**`특징`**

그래프 이론에 기반하며, 연결 중심성, 관계의 강도, 네트워크 구조 등을 분석 대상으로 한다.

**`활용 예`**

인플루언서 파악, 커뮤니티 탐지, 정보 확산 경로 분석

## 위기 요인과 통제 방안

### 위기 요인

**`사생활 침해`**

개인의 동의 없이 수집된 정보가 원래 목적과 다른 목적으로 활용되어 사생활을 침해할 위험이 있다.

**`책임 원칙 훼손`**

빅데이터 분석을 통한 예측 결과에 근거하여, 아직 실제로 일어나지 않은 일에 대해 특정인·집단에게 책임을 묻거나 불이익을 줄 위험이 있다.

**`데이터 오용`**

데이터 분석 결과가 절대적으로 완벽할 수 없음에도 이를 맹신하여, 잘못된 예측·판단에 근거해 의사결정을 내릴 위험이 있다.

### 통제 방안

**`사생활 침해의 통제방안 -> '동의'에서 '책임'으로`**

정보 제공자의 사전 동의를 구하는 방식만으로는 한계가 있으므로, 정보 사용자가 데이터를 활용한 결과에 대해 책임을 지도록 하는 사후 책임 원칙으로 전환한다.

**`책임 원칙 훼손의 통제방안 -> 결과 기반 책임 원칙 고수`**

예측 알고리즘에 의한 사전 판단이 아니라, 실제로 나타난 행동의 결과를 근거로 책임을 묻는 원칙을 고수한다.

**`알고리즘 접근 허용`**

데이터 오용을 통제하기 위해, 분석에 사용된 알고리즘의 작동 방식과 그 결과에 접근하여 타당성을 검증·반증할 수 있는 권리를 보장한다.
