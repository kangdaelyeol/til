## 전략 인사이트와 데이터 사이언스

### 인사이트

데이터의 가치는 크기가 아니라, 데이터로부터 얻을 수 있는 시각과 인사이트에 의해 결정된다.

빅데이터 분석의 가치는 비즈니스의 핵심 가치에 집중하고, 이와 관련된 분석 평가 지표를 개발하여 시장 고객 변화에 대한 효과적인 대응으로 이어질 때 가치를 발휘한다.

### 전략 도출을 위한 가치 기반 분석

일차적인 분석을 통해 분석 경험을 늘려 나아가며 분석의 활용 범위를 넓혀 전략적으로 변화시킴으로써 전략적 인사이트를 주는 **가치 기반 분석** 단계로 나아가야 한다.

전략적 수준의 분석은 인사이트 창출에 핵심적인 역할을 한다. 전략적인 인사이트 창출에 포커스를 두는 빅데이터 분석은 핵심 가치를 발휘한다.

### 데이터 사이언스

데이터 사이언스는 데이터로부터 의미 있는 정보를 추출해내는 학문이다.

**`데이터 마이닝과 관계`**

데이터 마이닝은 주로 분석에 포커스를 두지만, 데이터 사이언스는 분석을 포함하여 이를 효과적으로 구현하고 전달하여 전략적 인사이트를 도출하는 전 과정을 말한다.

**`데이터 사이언스 구성 요소`**

| 요소                | 종류                                                              |
| ------------------- | ----------------------------------------------------------------- |
| Analytics           | 수학, 통계학, 데이터 마이닝, 머신러닝 등 분석을 위한 이론적 지식  |
| IT(Data Management) | 프로그래밍, 시스템 엔지니어링, 데이터베이스 관리 등 기술적 요소   |
| 비즈니스 분석       | 해당 비즈니스·산업 도메인에 대한 이해와 통찰력, 커뮤니케이션 능력 |

**`데이터 사이언티스트에게 요구되는 역량`**

| 역량                    | 특징                                               | 종류                                                                                                  |
| ----------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 하드 스킬(Hard skill)   | 데이터 사이언스 관련 이론적 지식과 숙련도를 의미함 | 빅데이터에 대한 이론적 지식(통계학, 머신러닝 등), 분석 기술에 대한 숙련도(프로그래밍 등)              |
| 소프트 스킬(Soft skill) | 통찰력 있는 분석과 그 전달을 위한 자질을 의미함    | 창의적 사고, 호기심, 논리적 비판 등 통찰력 있는 분석 능력, 스토리텔링·시각화 등 설득력 있는 전달 능력 |

**`과학과 인문학의 교차로`**

데이터 사이언스의 역량인 소프트스킬은 인문학적 지식에 기반한다. 따라서 데이터 사이언스는 과학과 인문학의 교차로에 있다고 말한다.

소비자의 요구사항을 이해하기 위해서는 창조 과정에 주목하는 **인문학적 통찰력** 이 필요하다.

데이터 사이언티스트는 과학(정량분석)과 인문학적 통찰에 근거한 합리적 추론을 탁월하게 조합할 수 있어야 한다. 단순히 정보를 활용하는 수준을 넘어 사업 성과를 좌우하는 핵심적인 문제에 대답할 수 있는 수준의 인사이트를 제시해야 한다.

## 빅데이터 / 데이터 사이언스의 미래

### 가치 패러다임의 변화

`과거(Digitalization)` &rarr; `현재(Connection)` &rarr; `미래(Agency)`

| 개념                     | 가치 설명                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------ |
| 디지털화(Digitalization) | 아날로그 정보를 디지털 형태로 변환하여 컴퓨터가 처리·저장할 수 있게 되는 단계                    |
| 연결(Connection)         | 디지털화된 정보와 대상들이 네트워크로 서로 연결되어 초연결 사회를 이루는 단계                    |
| 에이전시(Agency)         | 연결된 데이터를 바탕으로 스스로 학습·판단하여 자율적으로 행동하는 주체(에이전트)가 등장하는 단계 |

### 데이터 사이언스의 한계

정량적 데이터 분석이라도 모든 분석은 가정에 근거하며, 가정이 변하지 않더라도 외부 요인은 계속해서 변화하기 때문에 완벽하지 않다.

데이터 사이언티스트는 가정과 현실의 불일치에 대해 끊임없이 고찰하고, 분석 모델이 예측할 수 없는 위험을 파악하기 위해 현실 세계를 주시해야 한다.
