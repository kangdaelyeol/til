## 데이터의 정의

**`정의`**

데이터란 관찰이나 측정을 통해 얻은, 다른 데이터와의 상관관계가 없는 가공되지 않은 사실이나 값을 의미한다. 수치, 문자, 기호, 이미지, 영상 등 다양한 형태로 존재한다.

**`어원`**

데이터(Data)는 라틴어 dare(주다)의 과거분사형인 datum(주어진 것)에서 유래되었으며, datum의 복수형이 data이다.

### 데이터의 특성

**`존재적 / 당위적 특성`**

| 구분        | 설명                                                                       | 예                    |
| ----------- | -------------------------------------------------------------------------- | --------------------- |
| 존재적 특성 | 가치 판단이 개입되지 않은, 있는 그대로의 객관적 사실                       | 수학 80점, 영어 100점 |
| 당위적 특성 | 특정 목적(문제 해결, 의사결정)에 맞게 재해석·가공되어 근거로 활용되는 성질 | 평균 90점             |

**`데이터 / 정보`**

데이터는 가공되지 않은 자료이며, 정보랑 구분되는 개념이다.

데이터에 의미와 가치가 부여될 때 정보가 된다.

### 데이터의 유형

**`정성적 / 정량적 데이터`**

| 구분          | 형태                                                                         | 예                      |
| ------------- | ---------------------------------------------------------------------------- | ----------------------- |
| 정성적 데이터 | 언어, 문자 등 비정형 형태로 존재하며, 저장·검색·분석에 비용이 많이 듦        | 인터뷰 내용, SNS 텍스트 |
| 정량적 데이터 | 수치, 도형, 기호 등으로 표현되며, 정형/반정형 형태로 저장·통계 분석이 용이함 | 시험 점수, 몸무게       |

**`정형 / 비정형 / 반정형 데이터`**

| 구분          | 형태                                                                      | 예                            |
| ------------- | ------------------------------------------------------------------------- | ----------------------------- |
| 정형 데이터   | 고정된 스키마(행과 열)에 따라 저장되어 형식이 규격화된 데이터             | RDB 테이블, 엑셀 스프레드시트 |
| 비정형 데이터 | 정해진 구조 없이 저장되어 값의 의미 파악이 어려운 데이터                  | 텍스트, 이미지, 음성, 영상    |
| 반정형 데이터 | 고정된 스키마는 아니지만 메타데이터를 포함해 구조를 유추할 수 있는 데이터 | XML, JSON, HTML, 웹로그       |

### 암묵지와 형식지

**`암묵지 / 형식지`**

| 구분                       | 설명                                                                         | 예                     |
| -------------------------- | ---------------------------------------------------------------------------- | ---------------------- |
| 암묵지(Tacit knowledge)    | 학습과 경험을 통해 개인에게 체화되어 있지만 언어·문자로 표현하기 어려운 지식 | 자전거 타는 법, 노하우 |
| 형식지(Explicit knowledge) | 문서나 매뉴얼처럼 형식을 갖추어 외부로 표현되어 전달·공유가 가능한 지식      | 업무 매뉴얼, 특허 문서 |

**`암묵지 / 형식지의 상호작용`**

```text
내면화 -> 공통화 --> 표출화 -> 연결화 -> 내면화 ...
```

| 암묵지 상호작용         | 설명                                                                |
| ----------------------- | ------------------------------------------------------------------- |
| 내면화(Internalization) | 형식지를 개인이 반복 학습·체화하여 자신의 암묵지로 전환하는 과정    |
| 공통화(Socialization)   | 경험을 공유함으로써 타인의 암묵지를 자신의 암묵지로 전이시키는 과정 |

| 형식지 상호작용         | 설명                                                        |
| ----------------------- | ----------------------------------------------------------- |
| 표출화(Externalization) | 암묵지를 언어나 문서 등으로 표현하여 형식지로 전환하는 과정 |
| 연결화(Combination)     | 개별 형식지들을 결합·체계화하여 새로운 형식지를 만드는 과정 |

### DIKW 피라미드

DIKW 피라미드란 데이터에서 지혜를 얻는 과정을 피라미드 형식으로 계층화한 개념이다.

| 단계              | 설명                                                                               |
| ----------------- | ---------------------------------------------------------------------------------- |
| Data(데이터)      | 다른 데이터와의 관계 속 의미가 부여되지 않은, 가공하지 않은 순수한 사실            |
| Information(정보) | 데이터를 가공·처리하여 데이터 간의 연관관계와 의미를 도출한 것                     |
| Knowledge(지식)   | 정보를 구조화·통합하여 도출한, 상호 연결된 패턴에 대한 이해                        |
| Wisdom(지혜)      | 지식의 축적과 아이디어의 결합으로 도출되는 창의적 산물, 근본 원리에 대한 깊은 이해 |

## 데이터베이스

### 다양한 측면에서의 특성

| 측면                     | 설명                                                                                                                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 정보의 축적 및 전달 측면 | **기계 가독성** : 대량의 정보를 일정한 형식에 맞춰 정보처리기기가 읽고 쓸 수 있음<br/> **검색 가능성** : 다양한 방법으로 정보를 검색할 수 있음<br/> **원격 조작성** : 정보통신망을 통해 원거리에서도 즉시 이용 가능 |
| 정보이용 측면            | 이용자의 정보요구에 따라 다양한 정보를 신속하게 획득할 수 있고, 원하는 정보를 정확하고 **경제적으로** 찾아낼 수 있음                                                                                                |
| 정보관리 측면            | 정보를 일정한 구조에 따라 관리할 수 있게 하여 방대한 양의 정보를 체계적으로 축적하고, 정보 추가나 갱신이 용이함                                                                                                     |
| 정보기술발전 측면        | 정보처리, 검색, 관리, S/W관련 H/W, 네트워크 기술 등의 발전을 견인할 수 있음                                                                                                                                         |
| 경제, 산업적 측면        | 다양한 정보를 신속하게 전달할 수 있는 인프라의 특성을 지니며, 이는 경제, 산업, 사회 활동의 효율성을 제고하고 국민의 편의를 증진하는 수단으로서의 의미를 가짐                                                        |

## 데이터베이스 활용

### 기업 내부의 데이터베이스

| 구분                                                                 | 설명                                                                                                            | 특징                                                            |
| -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| 인하우스 DB                                                          | 기업이 자체적으로 서버와 인력을 갖추고 직접 구축·운영하는 데이터베이스                                          | 보안성이 높고 신속한 접근이 가능하나 구축·운영 비용이 큼        |
| OLTP(Online Transaction Processing)                                  | 온라인상에서 실시간으로 발생하는 입력·수정·삭제 등의 트랜잭션을 처리하는 시스템                                 | 실시간성과 데이터 무결성이 중요하며 빠른 응답 속도가 요구됨     |
| OLAP(Online Analytical Processing)                                   | 축적된 데이터를 다차원적으로 분석하여 의사결정을 지원하는 시스템                                                | 다양한 관점에서 데이터를 조회·분석(Drill-down 등)할 수 있음     |
| CRM(Customer Relationship Management) / SCM(Supply Chain Management) | CRM은 고객 데이터를 분석해 마케팅에 활용하는 시스템, SCM은 조달부터 유통까지 공급망 전체를 통합 관리하는 시스템 | 고객관계 또는 공급망 데이터를 통합·분석해 경영 효율성을 높임    |
| EAI(Enterprise Application Integration)                              | 기업 내 서로 다른 플랫폼·애플리케이션 간의 정보와 프로세스를 연계해 하나의 통합 정보시스템으로 구성하는 솔루션  | 이질적인 시스템들을 유기적으로 연동·통합함                      |
| KMS(Knowledge Management System)                                     | 기업 내 개인·조직이 보유한 지식(암묵지 포함)을 발굴해 공유·활용하도록 지원하는 정보시스템                       | 암묵지를 형식지로 전환해 조직의 지식 자산으로 축적·공유함       |
| BI(Business Intelligence)                                            | 기업이 보유한 데이터를 수집·정리·분석해 의사결정에 활용하도록 지원하는 프로세스와 도구의 집합                   | 리포트·대시보드 등을 통해 데이터 기반 의사결정을 지원함         |
| RTE(Real Time Enterprise)                                            | 핵심 경영 정보를 실시간으로 파악하여 신속하게 대응할 수 있는 체계를 갖춘 기업                                   | 실시간 데이터 처리를 바탕으로 즉각적인 의사결정과 대응이 가능함 |

### 사회 기반 구조 데이터베이스

**`물류 부문`**

| 종류                                                  | 설명                                                                                            |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| CVO(Commercial Vehicle Operation)                     | 화물차량의 운행정보를 실시간으로 통합 관리하여 물류비용을 절감하는 첨단화물운송정보시스템       |
| EDI(Electronic Data Interchange)                      | 기업 간 거래 서류(주문서, 세금계산서 등)를 표준화된 전자문서 형태로 컴퓨터 간에 교환하는 시스템 |
| CALS(Continuous Acquisition and Life-cycle Support)   | 제품의 설계·생산부터 유통, 폐기까지 전 과정의 정보를 디지털화하여 통합 관리하는 시스템/전략     |
| PORT-MIS(Port Management Information System)          | 선박의 입출항 신고, 항만시설 사용 등 항만 관련 업무를 전산화하여 처리하는 항만운영정보시스템    |
| XROIS(eXtended Railroad Operating Information System) | 철도 화물의 운송 정보를 실시간으로 관리하는 철도물류정보시스템                                  |

**`지리 부문`**

| 종류                                | 설명                                                                                  |
| ----------------------------------- | ------------------------------------------------------------------------------------- |
| GIS(Geographic Information System)  | 지리적 위치를 기반으로 한 각종 정보를 컴퓨터로 종합 저장·분석·표현하는 지리정보시스템 |
| LBS(Location Based Service)         | GPS 등으로 얻은 위치정보를 기반으로 다양한 서비스를 제공하는 위치기반서비스           |
| SIM(Spatial Information Management) | 공간정보를 체계적으로 저장·관리·분석하여 활용할 수 있게 하는 공간정보관리체계         |

**`의료 부문`**

| 종류                                             | 설명                                                                                                            |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| PACS(Picture Archiving and Communication System) | 의료 영상(X-ray, CT, MRI 등)을 디지털화하여 저장·전송·조회할 수 있게 하는 의료영상저장전송시스템                |
| U-Health(Ubiquitous Health)                      | 정보통신기술을 활용해 시간과 장소에 구애받지 않고 건강관리·의료서비스를 받을 수 있는 유비쿼터스 헬스케어 서비스 |
