## 빅데이터의 이해

### 빅데이터의 정의

빅데이터는 측면에 따라 여러 의미로 정의된다.

| 주체                           | 정의                                                                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 일반적 정의                    | 기존 데이터베이스 관리도구로는 수집·저장·관리·분석하기 어려운 규모의 정형 및 비정형 데이터를 포함하여, 이로부터 가치를 추출하고 결과를 분석하는 기술 |
| 매킨지(Mckinsey) 정의          | 일반적인 데이터베이스 소프트웨어가 저장·관리·분석할 수 있는 범위를 초과하는 규모의 데이터로, 데이터 규모 자체에 초점을 둔 정의                       |
| IDC 정의                       | 다양한 종류의 대규모 데이터로부터 저렴한 비용으로 가치를 추출하고, 초고속의 수집·발굴·분석을 지원하도록 고안된 차세대 기술 및 아키텍처               |
| 더그 래니(Doug Laney)정의 - 3V | 규모(Volume)·다양성(Variety)·속도(Velocity)의 3가지 측면에서 급격히 증가하는 데이터                                                                  |
| 마이어쇤버거와 쿠키어의 정의   | 표본조사가 아닌 전체 데이터(N=all)를 대상으로 분석함으로써, 기존 방식으로는 어려웠던 상관관계와 통찰을 도출할 수 있게 하는 데이터                    |

### 빅데이터의 특징 - 3V / 4V

**`더그 래니의 3V`**

가트너 그룹의 부회장인 더그 래니(Doug Laney)는 빅데이터를 3V의 증가로 요약하였다.

| 구분     | 설명                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| Volume   | 저장 매체 가격 하락과 기술 발전에 따라 폭발적으로 증가하는 데이터의 규모                     |
| Variety  | 정형 데이터뿐 아니라 텍스트, 이미지, 로그 등 반정형·비정형 데이터까지 포함하는 형태의 다양성 |
| Velocity | 데이터가 생성·수집·처리·분석되는 속도가 실시간에 가깝게 빨라지는 특성                        |

**`빅데이터의 새로운 특징 - 4V`**

Doug Laney의 3V 특징의 추가로 특징을 두어 4V로 빅데이터의 특징을 설명하기도 한다. 추가 특징은 다양하게 해석된다.

| 구분                | 설명                                                                      |
| ------------------- | ------------------------------------------------------------------------- |
| Value               | 다양한 분석을 통해 새로운 가치를 창출할 수 있어야 한다는 특성             |
| Veracity(정확성)    | 데이터의 신뢰성과 품질을 확보하여 분석 결과의 정확성을 보장해야 하는 특성 |
| Visualization       | 방대하고 복잡한 데이터를 이해하기 쉽도록 시각적으로 표현하는 특성         |
| Variability(가변성) | 동일한 데이터라도 상황·문맥에 따라 의미와 가치가 달라지는 특성            |

### 빅데이터 출현 배경

빅데이터는 새롭게 등장한 개념으로 보는 것이 아닌, 기술의 패러다임 시프트 현상으로 바라봐야 한다.

**`산업계의 변화`**

산업계에서 일어난 빅데이터 현상을 **양질 전환의 법칙** 으로 설명하기도 한다.

- 양질 전환의 법칙은 헤겔의 변증법에 기초를 둔 개념으로, 양적인 변화가 축적되면 질적인 변화도 이루어진다는 개념이다.

양질 전환의 법칙은 정보가 지속적으로 축적되면서 거대한 데이터는 새로운 기술을 만나 새로운 가치를 창출할 수 있는 변화의 상태가 된다고 설명한다.

**`관련 기술의 발전 - 클라우드 컴퓨팅`**

클라우드 컴퓨팅은 대용량의 데이터를 병렬 분산처리 시스템으로 처리할 경우 비용이 혁신적으로 줄어든다는 특징이 있으며, 이는 빅데이터를 분석하고 새로운 가치를 창출하는 데 기여했다고 볼 수 있다.

### 빅데이터의 비유적 특징

| 비유                | 설명                                                                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 산업혁명의 석탄, 철 | 산업혁명 시기의 석탄·철처럼 다른 산업, 정부 정책, 개인의 삶 전반에 융합되어 사회 전반에 혁명적 변화를 가져올 것으로 기대                 |
| 21세기 원유         | 원유가 정제를 거쳐 다양한 제품으로 활용되듯, 빅데이터도 분석·가공을 거쳐 여러 산업에서 새로운 가치를 창출하는 핵심 자원이 될 것으로 기대 |
| 렌즈                | 현미경이 세포를 관찰하게 하여 생물학 발전을 이끌었듯, 빅데이터는 사회의 변화를 관찰하고 대응하게 하는 렌즈 역할을 할 것으로 기대         |
| 플랫폼              | 플랫폼처럼 여러 주체가 공동으로 활용할 수 있는 기반이 되어, 다양한 서드파티 비즈니스에 활용될 것으로 기대                                |

### 빅데이터가 만들어내는 변화

| 구분                 | 설명                                                                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 사전처리 -> 사후처리 | 목적에 맞게 데이터를 미리 정제해 저장하던 방식에서, 일단 대량의 데이터를 모두 저장한 후 필요할 때 사후적으로 가공·분석하는 방식으로 변화 |
| 표본조사 -> 전수조사 | 제한된 표본을 추출해 분석하던 방식에서, 모든 데이터(N=all)를 대상으로 분석하는 방식으로 변화                                             |
| 질 -> 양             | 데이터의 정확성(질)보다 확보한 데이터의 양이 더 유의미한 결과를 가져온다는 관점으로 변화                                                 |
| 인과관계 -> 상관관계 | 왜(Why) 발생했는지의 인과관계 규명보다, 무엇(What)이 함께 발생하는지의 상관관계 파악을 중시하는 방향으로 변화                            |
