## 통계 개요

### 표본조사

모집단 전체를 조사하는 것을 전수조사라고 한다. 모집단의 크기가 매우 커서 전수조사가 어려운 경우, 모집단의 일부인 표본을 추출해 조사하는 표본조사를 실시한다.

표본조사의 결과를 믿으려면 표본이 모집단의 특성을 잘 반영해야 하며, 이를 표본의 대표성이라고 한다.

- 대표성은 표본을 뽑는다고 저절로 생기지 않으므로, 적절한 표본추출 방법을 사용해 확보해야 한다.

### 표본추출 방법

| 방법                       | 설명                                                                                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 단순 랜덤 추출법           | 모집단의 각 원소가 동일한 확률로 선택되도록 무작위로 추출한다.                                                                                                 |
| 계통 추출법                | 모집단의 원소에 번호를 매긴 뒤, 첫 번째 원소만 무작위로 고르고 이후 일정한 간격(K)마다 추출한다. 데이터에 주기성이 있으면 편향될 수 있다.                      |
| 집락(군집, Cluster) 추출법 | 모집단을 여러 군집으로 나누고, 일부 군집을 무작위로 선택해 선택된 군집의 원소를 조사한다. 군집 내부는 이질적이고 군집 간에는 동질적인 경우에 적합하다.         |
| 층화 추출법                | 모집단을 서로 겹치지 않는 여러 층으로 나누고, 각 층에서 무작위로 추출한다. 층 내부는 동질적이고 층 간에는 이질적인 경우에 적합하다. (예: 연령대별로 나눠 추출) |

### 복원/비복원 추출

| 구분        | 설명                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------- |
| 복원 추출   | 추출한 원소를 다시 모집단에 넣고 다음 원소를 추출한다. 같은 원소가 여러 번 뽑힐 수 있고, 각 추출은 독립적이다. |
| 비복원 추출 | 추출한 원소를 다시 넣지 않고 다음 원소를 추출한다. 같은 원소가 중복으로 뽑히지 않는다.                         |

### 측정과 척도

| 구분 | 설명                                                                                   |
| ---- | -------------------------------------------------------------------------------------- |
| 측정 | 표본집단을 주어진 목적에 적합하게 관측해 자료를 얻는 것                                |
| 척도 | 관측 대상의 속성을 측정하여 그 값이 숫자로 나타나도록 일정한 규칙을 정하여 바꾸는 도구 |

### 척도의 종류

| 구분      | 종류            | 설명                                                                                                        |
| --------- | --------------- | ----------------------------------------------------------------------------------------------------------- |
| 질적 척도 | 명목척도        | 단순히 범주를 구분하기 위한 척도로, 순서나 크기의 의미가 없다. (예: 성별, 혈액형, 출생지)                   |
| 질적 척도 | 순서(서열) 척도 | 범주 사이에 순서(대소) 관계가 있지만, 값 사이의 간격은 의미가 없다. (예: 학년, 선호도, 만족도)              |
| 양적 척도 | 구간(등간) 척도 | 값 사이의 간격이 일정해 덧셈·뺄셈이 가능하지만, 절대적 0점이 없어 비율 계산은 의미가 없다. (예: 온도, 지수) |
| 양적 척도 | 비율척도        | 절대적 0점이 존재해 사칙연산(비율 계산 포함)이 모두 가능하다. (예: 무게, 나이, 시간, 금액)                  |

- 구간척도와 비율척도의 구분 기준은 절대적 0점의 유무이다. 0℃는 "온도가 없음"이 아니므로 20℃가 10℃의 2배라고 할 수 없지만, 0kg은 "무게가 없음"이므로 20kg은 10kg의 2배이다.

### 기술통계/추론통계

| 구분           | 설명                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------- |
| 기술통계       | 수집한 표본 데이터의 특성을 평균, 분산, 표준편차, 빈도, 그래프 등으로 요약·정리해 나타내는 통계    |
| 추론(추리)통계 | 표본에서 얻은 정보를 바탕으로 모집단의 특성(모수)을 추정하거나, 모집단에 대한 가설을 검정하는 통계 |

## 이산확률분포

### 이산확률변수

확률변수란 시행 결과에 따라 값이 확률적으로 정해지는 변수이다. 이 중 이산확률변수는 0, 1, 2, ...처럼 셀 수 있는 값만 가지는 확률변수이며, 각 값이 나올 확률을 확률질량함수(PMF)로 나타낸다.

| 종류          | 설명                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 베르누이 분포 | 결과가 성공/실패 두 가지뿐인 시행을 1번 했을 때의 분포. 성공 확률이 p이면 E(X) = p, V(X) = p(1-p) (예: 동전 1번 던지기)                     |
| 이항 분포     | 성공 확률이 p인 베르누이 시행을 n번 독립적으로 반복했을 때 성공 횟수의 분포. E(X) = np, V(X) = np(1-p)                                      |
| 기하 분포     | 성공 확률이 p인 베르누이 시행에서 처음 성공할 때까지 시행한 횟수의 분포. E(X) = 1/p (예: 처음 6이 나올 때까지 주사위 던진 횟수)             |
| 다항 분포     | 이항 분포를 결과가 3가지 이상인 경우로 확장한 분포. n번 시행했을 때 각 결과가 나온 횟수를 다룬다. (예: 주사위 n번 던지기)                   |
| 포아송 분포   | 단위 시간이나 단위 공간에서 어떤 사건이 발생하는 횟수의 분포. 평균 발생 횟수 λ로 정해지며 E(X) = V(X) = λ (예: 1시간 동안 걸려오는 전화 수) |

## 연속확률분포

### 연속확률변수

키, 무게, 시간처럼 일정 구간 안의 모든 실수 값을 가질 수 있는 확률변수이다. 확률은 확률밀도함수(PDF) 아래의 면적으로 구하므로, 특정한 한 점의 확률은 0이다.

| 종류          | 설명                                                                                                                                                                                                           |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 균일 분포     | 구간 [a, b] 안의 모든 값이 나올 확률(밀도)이 동일한 분포. E(X) = (a+b)/2                                                                                                                                       |
| 정규 분포     | 평균 μ를 중심으로 좌우 대칭인 종 모양의 분포로, N(μ, σ²)로 표기한다. Z = (X-μ)/σ로 변환하면 평균 0, 분산 1인 표준정규분포 N(0, 1)이 된다.                                                                      |
| t-분포        | 평균 0을 중심으로 좌우 대칭이지만 정규분포보다 꼬리가 두꺼운 분포. 모분산을 모를 때 표본평균으로 모평균을 추론하거나 두 집단의 평균을 비교(t-검정)할 때 사용한다. 자유도가 커질수록 표준정규분포에 가까워진다. |
| 카이제곱 분포 | k개의 서로 독립인 표준정규 확률변수를 각각 제곱해 더한 값의 분포(자유도 k). 0 이상의 값만 가지며 오른쪽으로 꼬리가 긴 비대칭 분포이다. 모분산 검정, 범주형 자료의 적합도·독립성 검정에 사용한다.               |
| F 분포        | 서로 독립인 두 카이제곱 확률변수를 각각의 자유도로 나눈 뒤 구한 비율의 분포. 0 이상의 값만 가지며 두 집단의 분산 비교(등분산 검정)와 분산분석(ANOVA)에 사용한다.                                               |

## 기댓값, 분산, 표준편차, 첨도와 왜도

| 개념                  | 설명                                                                                                                                                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 기댓값                | 확률변수가 가질 수 있는 각 값에 그 값이 나올 확률을 곱해 모두 더한 값으로, 확률변수의 평균을 의미한다. 이산형은 E(X) = Σx·P(x), 연속형은 E(X) = ∫x·f(x)dx                                                        |
| 분산                  | 확률변수의 값이 기댓값(평균)으로부터 얼마나 흩어져 있는지를 나타낸다. V(X) = E[(X-μ)²] = E(X²) - [E(X)]². 편차를 제곱하므로 단위가 원래 데이터 단위의 제곱이 된다.                                               |
| 표준편차              | 분산의 양의 제곱근(σ = √V(X)). 단위가 원래 데이터와 같아서 흩어진 정도를 직관적으로 해석하기 쉽다.                                                                                                               |
| 공분산(covariance)    | 두 확률변수가 함께 변하는 방향을 나타낸다. Cov(X, Y) = E[(X-μx)(Y-μy)]. 양수면 같은 방향, 음수면 반대 방향으로 변하고, 0이면 선형 관계가 없다. 값의 크기가 단위에 따라 달라지므로 관계의 강도를 비교하기 어렵다. |
| 상관계수(correlation) | 공분산을 두 변수의 표준편차의 곱으로 나눠 단위의 영향을 없앤 값. ρ = Cov(X, Y) / (σx·σy). -1 ~ 1 사이의 값을 가지며, 절댓값이 1에 가까울수록 선형 관계가 강하고 0에 가까울수록 약하다.                           |
| 첨도(kurtosis)        | 분포가 평균 주변에 얼마나 뾰족하게 몰려 있는지(꼬리가 얼마나 두꺼운지)를 나타낸다. 정규분포의 첨도는 3이며, 3을 뺀 값(초과 첨도)을 쓰면 정규분포가 0이 된다. 값이 클수록 뾰족하고 꼬리가 두껍다.                 |
| 왜도(skewness)        | 분포가 좌우로 얼마나 비대칭인지를 나타낸다. 0이면 좌우 대칭, 양수면 오른쪽 꼬리가 긴 분포, 음수면 왼쪽 꼬리가 긴 분포이다.                                                                                       |

- 기댓값과 분산의 성질: E(aX + b) = aE(X) + b, V(aX + b) = a²V(X). 모든 값에 상수 b를 더해도 흩어진 정도는 그대로이므로 분산은 변하지 않는다.

- 공분산이 0이라고 두 변수가 독립인 것은 아니다. 독립이면 공분산은 0이지만, 공분산이 0이어도 비선형 관계는 있을 수 있다.

- 왜도에 따른 평균·중앙값·최빈값의 위치

  | 왜도            | 분포 모양          | 대소 관계              |
  | --------------- | ------------------ | ---------------------- |
  | 왜도 = 0        | 좌우 대칭          | 평균 = 중앙값 = 최빈값 |
  | 왜도 > 0 (양수) | 오른쪽 꼬리가 길다 | 최빈값 < 중앙값 < 평균 |
  | 왜도 < 0 (음수) | 왼쪽 꼬리가 길다   | 평균 < 중앙값 < 최빈값 |

## 추정과 가설검정

### 모수의 추정

통계적 방법론에서 궁극적으로 알고 싶은 모평균, 모분산과 같은 모집단의 특성값을 모수라고 한다.

현실적으로 모집단 전체를 조사해 모수를 구하는 것은 거의 불가능하기 때문에, 대부분 표본조사로 얻은 통계량(표본평균, 표본분산 등)을 이용해 모수를 추정한다.

### 추정

통계적 추정은 표본의 정보를 이용해 모수의 값을 추측하는 것이다.

| 종류     | 설명                                                                                                                                                                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 점추정   | 모수를 하나의 값으로 추정한다. (예: 표본평균 72점으로 모평균을 72점이라고 추정) 좋은 추정량의 조건으로 불편성(추정량의 기댓값이 모수와 같음), 효율성(분산이 작음), 일치성(표본이 커질수록 모수에 가까워짐), 충족성(모수에 대한 정보를 충분히 담음)이 있다. |
| 구간추정 | 모수가 포함될 것으로 기대되는 범위를 신뢰수준과 함께 추정한다. (예: 모평균은 95% 신뢰수준에서 70 ~ 74점) 모분산을 알 때 모평균의 95% 신뢰구간은 x̄ ± 1.96·σ/√n 이다.                                                                                        |

- 95% 신뢰구간의 의미: 같은 방법으로 표본을 100번 뽑아 신뢰구간을 100개 만들면, 그중 약 95개가 실제 모수를 포함한다는 뜻이다. 모수는 고정된 값이므로 "모수가 이 구간에 있을 확률이 95%"라는 해석은 엄밀히는 틀리다.

- 신뢰수준을 높이면(95% → 99%) 구간이 넓어지고, 표본 크기 n을 늘리면 구간이 좁아진다.

### 가설검정

통계적 가설검정은 모집단의 특성에 대한 주장 또는 가설을 세우고 표본에서 얻은 정보를 기반으로 가설이 옳은지를 판정하는 과정이다.

| 종류                             | 설명                                                                                                                                                                                |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 귀무가설(null hypothesis)        | "차이가 없다", "효과가 없다"처럼 기존에 받아들여지던 주장으로, H0으로 표기한다. 검정은 귀무가설을 기각할 수 있는지를 판단하는 방식으로 진행된다. (예: 신약과 기존 약의 효과는 같다) |
| 대립가설(alternative hypothesis) | 귀무가설이 기각될 때 채택되는 가설로, 연구자가 입증하고 싶은 주장이다. H1으로 표기한다. (예: 신약이 기존 약보다 효과가 있다)                                                        |

- 귀무가설을 기각하지 못했다고 귀무가설이 참이라고 증명된 것은 아니다. "차이가 있다고 말할 근거가 부족하다"는 뜻이다.

### 제1종 제2종 오류

| 종류       | 설명                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| 제1종 오류 | 귀무가설이 참인데 귀무가설을 기각하는 오류. 발생 확률을 α로 표기한다. (예: 효과 없는 약을 효과 있다고 판단)          |
| 제2종 오류 | 귀무가설이 거짓인데 귀무가설을 기각하지 못하는 오류. 발생 확률을 β로 표기한다. (예: 효과 있는 약을 효과 없다고 판단) |

- 1 - β를 검정력(power)이라고 하며, 귀무가설이 거짓일 때 이를 올바르게 기각할 확률이다.

- 표본 크기가 고정되어 있으면 α를 줄일수록 β가 커지는 상충 관계가 있다. 그래서 보통 α를 먼저 정해 두고(유의수준) β가 작아지도록 검정을 설계한다.

### 검정통계량과 기각역

| 종류                       | 설명                                                                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 검정통계량(test statistic) | 귀무가설을 기각할지 판단하기 위해 표본 데이터로 계산한 값. 검정 방법에 따라 z값, t값, 카이제곱값, F값 등이 쓰인다.                 |
| 기각역                     | 검정통계량이 이 범위에 들어가면 귀무가설을 기각하는 영역. 유의수준 α에 따라 정해진다. (예: α = 0.05인 양측 z검정이면 \|z\| > 1.96) |

### 유의수준과 유의확률

| 종류                               | 설명                                                                                                                          |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 유의수준(significance level)       | 제1종 오류를 범할 확률의 최대 허용 한계로, α로 표기한다. 검정 전에 연구자가 정하며 보통 0.05 또는 0.01을 사용한다.            |
| 유의확률(significance probability) | p-value라고도 한다. 귀무가설이 참이라고 가정했을 때, 실제로 관측된 검정통계량만큼 또는 그보다 더 극단적인 값이 나올 확률이다. |

- 판단 기준: p-value < α 이면 귀무가설을 기각하고, p-value ≥ α 이면 귀무가설을 기각하지 못한다.

- 직관적 해석: p-value가 작다는 것은 "귀무가설이 맞다면 이런 결과가 나오기 매우 어렵다"는 뜻이므로, 귀무가설을 의심하고 기각하게 된다.

### 모수 검정과 비모수 검정

두 검정을 나누는 기준은 모집단의 분포에 대한 가정을 하느냐이다.

| 종류                       | 설명                                                                                                                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 모수(parametric) 검정      | 모집단이 특정 분포(주로 정규분포)를 따른다고 가정하고, 그 분포의 모수(평균, 분산 등)에 대해 검정한다. 관측값의 실제 크기(평균, 분산)를 이용해 검정통계량을 계산한다.                   |
| 비모수(nonparametric) 검정 | 모집단의 분포에 대해 특정한 가정을 하지 않는 검정이다. 관측값의 실제 크기 대신 순위(rank)나 부호(+, -)를 이용해 검정통계량을 계산하며, 평균 대신 중앙값이나 분포의 위치 등을 비교한다. |

**`예시 - 두 반의 시험 점수를 비교할 때`**

모수 검정은 "두 반의 점수가 정규분포를 따른다"고 가정하고 두 반의 평균 점수를 비교한다 (독립 2표본 t-검정).

비모수 검정은 분포를 가정하지 않고, 두 반 학생을 모두 섞어 점수 순서대로 1등, 2등, ... 순위를 매긴 뒤 어느 반에 높은 순위가 몰려 있는지를 비교한다 (만-위트니 U 검정).

한 학생이 1000점처럼 잘못 입력돼도, 평균은 크게 흔들리지만 순위는 "1등" 하나로만 반영되므로 비모수 검정은 이상값의 영향을 덜 받는다.

**`모수 검정과 비모수 검정 비교`**

| 구분        | 모수 검정                            | 비모수 검정                                      |
| ----------- | ------------------------------------ | ------------------------------------------------ |
| 분포 가정   | 정규분포 등 특정 분포를 가정         | 분포 가정 없음 (분포무관 검정)                   |
| 사용하는 값 | 관측값의 실제 크기 (평균, 분산)      | 순위, 부호                                       |
| 적합한 자료 | 구간척도, 비율척도                   | 명목척도, 순서척도 (구간·비율척도에도 사용 가능) |
| 표본 크기   | 충분히 클 때 적합                    | 표본이 작아 정규성을 확인하기 어려울 때 유용     |
| 이상값      | 영향을 크게 받음                     | 영향을 적게 받음                                 |
| 검정력      | 가정을 만족하면 비모수 검정보다 높음 | 가정을 만족하는 상황에서는 모수 검정보다 낮음    |

**`언제 비모수 검정을 쓰는가`**

정규성 검정 결과 정규분포를 따르지 않는 경우

표본 크기가 작아 정규분포 가정을 확신할 수 없는 경우

자료가 순위나 등급(순서척도)처럼 평균을 내는 것이 의미 없는 경우

이상값이 많아 평균이 대표성을 갖기 어려운 경우

| 분석 목적                          | 모수 검정                | 비모수 검정                           |
| ---------------------------------- | ------------------------ | ------------------------------------- |
| 한 집단 또는 대응 표본(전·후) 비교 | 일표본 / 대응표본 t-검정 | 부호 검정, 윌콕슨 부호순위 검정       |
| 독립된 두 집단 비교                | 독립 2표본 t-검정        | 만-위트니 U 검정 (윌콕슨 순위합 검정) |
| 세 집단 이상 비교                  | 일원분산분석(ANOVA)      | 크루스칼-왈리스 검정                  |
| 두 변수의 상관관계                 | 피어슨 상관계수          | 스피어만 순위상관계수                 |
| 데이터의 무작위성                  | -                        | 런 검정                               |

## t-검정

t-검정은 모집단의 분산(표준편차)을 모를 때, 표본에서 구한 표준편차와 t-분포를 이용해 평균에 대한 가설을 검정하는 모수 검정이다.

- 기본 가정: 데이터가 정규분포를 따른다 (정규성). 표본이 작을수록 이 가정이 중요하며, Shapiro-Wilk 검정(R: `shapiro.test()`) 등으로 확인한다.
- 정규성을 만족하지 않으면 같은 목적의 비모수 검정(윌콕슨 부호순위 검정, 만-위트니 U 검정 등)을 사용한다.

**`단측 검정과 양측 검정`**

t-검정 종류와 관계없이, 대립가설의 방향에 따라 단측 검정과 양측 검정으로 나뉜다.

| 종류      | 설명                                                                                                            |
| --------- | --------------------------------------------------------------------------------------------------------------- |
| 단측 검정 | 대립가설이 "크다" 또는 "작다"처럼 한쪽 방향만 주장하는 검정. 기각역이 분포의 한쪽 끝에만 있다. (예: H1: μ < 50) |
| 양측 검정 | 대립가설이 "다르다"처럼 방향을 정하지 않는 검정. 기각역이 분포의 양쪽 끝에 α/2씩 나뉘어 있다. (예: H1: μ ≠ 50)  |

- 같은 유의수준이라도 단측 검정의 기각 기준값이 양측 검정보다 작다. (자유도 9, α = 0.05일 때 단측 1.833, 양측 2.262)

### 일 표본 t-검정(one sample t-test)

일 표본 t-검정은 가설검정의 일종으로, 하나의 모집단의 평균값을 특정값과 비교하는 경우 사용하는 통계적 분석 방법이다.

- 검정통계량: t = (x̄ - μ0) / (s / √n), 자유도 = n - 1 (x̄: 표본평균, μ0: 비교할 특정값, s: 표본표준편차, n: 표본 크기)

일 표본 t-검정은 단측 / 양측으로 구분된다.

| 종류                | 설명                                                                                                    |
| ------------------- | ------------------------------------------------------------------------------------------------------- |
| 일 표본 단측 t-검정 | 모평균이 특정값보다 크다(또는 작다)는 한쪽 방향의 주장을 검정한다. H0: μ = μ0, H1: μ > μ0 (또는 μ < μ0) |
| 일 표본 양측 t-검정 | 모평균이 특정값과 다르다는 주장을 검정한다. 방향은 따지지 않는다. H0: μ = μ0, H1: μ ≠ μ0                |

**`일 표본 t-검정 예시`**

과자 봉지에 "50g"이라고 표기되어 있는데, 실제로는 더 적게 들어 있는지 확인하고 싶다. 10봉지를 무작위로 골라 무게를 쟀다.

- 데이터: 48, 49, 51, 47, 50, 48, 49, 46, 50, 48 (g)
- 가설: H0: μ = 50, H1: μ < 50 → "적다"는 한쪽 방향이므로 단측 검정
- 계산: x̄ = 48.6, s ≈ 1.506, n = 10 → t = (48.6 - 50) / (1.506 / √10) ≈ -2.94, 자유도 = 9
- 판단: 자유도 9, α = 0.05인 단측 검정의 기각 기준은 t < -1.833이다. -2.94는 기각역에 들어가므로 귀무가설을 기각한다.
- 결론: 유의수준 5%에서 과자의 평균 무게는 표기된 50g보다 적다고 할 수 있다.

```r
x <- c(48, 49, 51, 47, 50, 48, 49, 46, 50, 48)
t.test(x, mu = 50, alternative = "less")   # 양측 검정이면 alternative = "two.sided" (기본값)
```

### 이(독립) 표본 t-검정(independent sample t-test)

이 표본 t-검정 또한 가설검정의 일종으로 서로 **독립된** 두 개의 집단에 대하여 모수(모평균)의 값이 같은지 통계적으로 검정하는 방법.

- 독립표본 t-검정이라고도 부른다.
- 기본 가정: 두 집단은 서로 독립이고, 각 집단이 정규분포를 따른다.
- 등분산 가정: 두 집단의 분산이 같은지에 따라 검정 방법이 달라지므로, 먼저 등분산 검정(F 검정, R: `var.test()`)을 실시한다. 분산이 같으면 합동 분산을 쓰는 Student t-검정, 다르면 Welch t-검정을 사용한다.

이 표본 t-검정은 단측 / 양측으로 구분된다.

| 종류                | 설명                                                                                                        |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| 이 표본 단측 t-검정 | 한 집단의 모평균이 다른 집단보다 크다(또는 작다)는 주장을 검정한다. H0: μ1 = μ2, H1: μ1 > μ2 (또는 μ1 < μ2) |
| 이 표본 양측 t-검정 | 두 집단의 모평균이 다르다는 주장을 검정한다. H0: μ1 = μ2, H1: μ1 ≠ μ2                                       |

**`이 표본 t-검정 예시`**

서로 다른 교수법으로 수업한 A반과 B반의 시험 점수에 차이가 있는지 확인하고 싶다. 각 반에서 6명씩 무작위로 뽑았다.

- 데이터: A반 78, 85, 82, 88, 75, 80 / B반 72, 76, 70, 79, 74, 71
- 가설: H0: μA = μB, H1: μA ≠ μB → "차이가 있다"이므로 양측 검정
- 등분산 검정: 분산비 F = 22.27 / 11.47 ≈ 1.94로, 자유도 (5, 5)에서 α = 0.05 양측 검정의 기각 기준값(약 7.15)보다 작다 → 등분산 가정을 받아들이고 Student t-검정을 사용한다.
- 계산: x̄A ≈ 81.33, x̄B ≈ 73.67, 합동 표준편차 ≈ 4.107 → t ≈ 3.23, 자유도 = 6 + 6 - 2 = 10
- 판단: 자유도 10, α = 0.05인 양측 검정의 기각 기준은 |t| > 2.228이다. 3.23은 기각역에 들어가므로 귀무가설을 기각한다.
- 결론: 유의수준 5%에서 두 반의 평균 점수에는 차이가 있다고 할 수 있다.

```r
a <- c(78, 85, 82, 88, 75, 80)
b <- c(72, 76, 70, 79, 74, 71)
var.test(a, b)                    # 등분산 검정
t.test(a, b, var.equal = TRUE)    # 등분산이면 TRUE, 아니면 FALSE(기본값, Welch t-검정)
```

### 대응 표본 t-검정(paired t-test)

동일한 대상에 대해 두 가지 관측치가 있는 경우 이를 비교하여 차이가 있는지 검정하는 방법.

일반적으로 실험 전후의 효과를 비교하기 위해 사용한다.

- 독립 표본 t-검정과의 차이: 두 관측치가 같은 대상에서 나왔으므로 서로 독립이 아니다. 그래서 대상별로 두 값의 차이(d)를 먼저 구하고, 차이의 평균이 0인지를 일 표본 t-검정과 같은 방식으로 검정한다.
- 검정통계량: t = d̄ / (sd / √n), 자유도 = n - 1 (d̄: 차이의 평균, sd: 차이의 표준편차, n: 대상 수)
- 기본 가정: 차이(d)가 정규분포를 따른다.

**`대응 표본 t-검정 예시`**

6명이 4주간 다이어트 프로그램에 참여했다. 프로그램 전후 체중에 차이가 있는지 확인하고 싶다.

- 데이터

  | 참가자   | 1   | 2   | 3   | 4   | 5   | 6   |
  | -------- | --- | --- | --- | --- | --- | --- |
  | 전 (kg)  | 82  | 90  | 75  | 88  | 95  | 79  |
  | 후 (kg)  | 79  | 86  | 74  | 84  | 90  | 77  |
  | 차이 (d) | 3   | 4   | 1   | 4   | 5   | 2   |

- 가설: H0: μd = 0, H1: μd ≠ 0 → "차이가 있다"이므로 양측 검정
- 계산: d̄ ≈ 3.17, sd ≈ 1.472, n = 6 → t = 3.17 / (1.472 / √6) ≈ 5.27, 자유도 = 5
- 판단: 자유도 5, α = 0.05인 양측 검정의 기각 기준은 |t| > 2.571이다. 5.27은 기각역에 들어가므로 귀무가설을 기각한다.
- 결론: 유의수준 5%에서 다이어트 프로그램 전후의 체중에는 차이가 있다고 할 수 있다.

```r
before <- c(82, 90, 75, 88, 95, 79)
after  <- c(79, 86, 74, 84, 90, 77)
t.test(before, after, paired = TRUE)
```

- R 결과 해석: `t.test()`는 t값, 자유도(df - degrees of freedom), p-value, 신뢰구간을 출력한다. 시험에서는 p-value를 유의수준(보통 0.05)과 비교해 p-value < 0.05이면 귀무가설을 기각한다고 판단하면 된다.

## 분산분석(ANOVA - Analysis of Variance)

### 분산분석 개요

세 개 이상의 모집단이 있을 경우에 여러 집단 사이의 평균을 비교하는 검정방법을 분산분석이라고 한다.

- 평균을 비교하는데 "분산"분석이라고 부르는 이유: 집단 간의 차이(집단 평균끼리 흩어진 정도)가 집단 내부의 차이(각 집단 안에서 값들이 흩어진 정도)보다 충분히 큰지를 분산의 비율로 판단하기 때문이다.
- t-검정을 여러 번 하지 않는 이유: 세 집단(A, B, C)을 t-검정으로 비교하면 A-B, A-C, B-C 3번 검정해야 하고, 검정을 반복할수록 제1종 오류가 누적되어 커진다. 분산분석은 한 번의 검정으로 전체를 비교한다.
- 독립변수(요인)는 범주형, 종속변수는 연속형이어야 한다. (예: 교수법 A/B/C → 시험 점수)

**`분산분석 특징`**

| 특징                           | 설명                                                                                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 귀무가설                       | 귀무가설은 항상 "모든 집단 간 평균은 같다"이다. (H0: μ1 = μ2 = ... = μk) 대립가설은 "적어도 한 집단의 평균은 다르다"이다.                                             |
| 정규성                         | 각 집단의 데이터가 정규분포를 따라야 한다. (R: `shapiro.test()`)                                                                                                      |
| 등분산성                       | 모든 집단의 분산이 같아야 한다. (R: `bartlett.test()` 등)                                                                                                             |
| 독립성                         | 각 집단의 관측값은 서로 독립이어야 한다.                                                                                                                              |
| F-value                        | 검정통계량으로 F = 집단 간 평균제곱(MSB) / 집단 내 평균제곱(MSW)을 사용한다. F값이 클수록 집단 간 차이가 크다는 뜻이며, F 분포를 따른다.                              |
| 귀무가설 기각 시 사후검정 필요 | 분산분석은 "적어도 한 집단이 다르다"까지만 알려주고, 어느 집단끼리 다른지는 알려주지 않는다. 그래서 사후검정(Tukey HSD, Scheffe, Bonferroni, Duncan 등)으로 확인한다. |

### 일원분산분석(one-way ANOVA)

범주형 독립변수(요인)가 1개, 연속형 종속변수가 1개일 때 사용하는 방법.

- 예: 교수법(A/B/C, 요인 1개)에 따라 시험 점수(종속변수)에 차이가 있는가

**`제곱합 용어 요약`**

| 용어                                                  | 설명                                                                                                                                                             |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SSE(residual sum of squares, sum squared errors)      | 각 관측값과 그 관측값이 속한 집단 평균의 차이를 제곱해 더한 값. 모델로 설명되지 않는 변동(오차)이다. 분산분석에서는 집단 내 제곱합(SSW)이라고도 한다.            |
| SSR(explained sum of squares, sum squared regression) | 각 집단 평균과 전체 평균의 차이를 제곱해 (집단 크기만큼 가중해) 더한 값. 모델(집단의 차이)로 설명되는 변동이다. 분산분석에서는 집단 간 제곱합(SSB)이라고도 한다. |
| SST(total sum of squares)                             | 각 관측값과 전체 평균의 차이를 제곱해 더한 값. 데이터 전체의 변동이다.                                                                                           |

- 세 제곱합의 관계: SST = SSR + SSE (전체 변동 = 설명되는 변동 + 설명되지 않는 변동)
- 평균제곱(MS)은 제곱합을 자유도로 나눈 값이다. 집단 수가 k, 전체 관측값 수가 N일 때
  - MSB = SSR / (k - 1), MSW = SSE / (N - k), F = MSB / MSW

**`일원분산분석 예시`**

세 가지 교수법(A, B, C)으로 수업한 학생들의 시험 점수에 차이가 있는지 확인하고 싶다. 각 교수법마다 5명씩 무작위로 뽑았다.

- 데이터: A 70, 72, 68, 75, 70 / B 78, 80, 76, 82, 79 / C 71, 74, 69, 73, 73
- 가설: H0: μA = μB = μC, H1: 적어도 한 교수법의 평균 점수는 다르다
- 계산: 집단 평균 A = 71, B = 79, C = 72, 전체 평균 = 74

  | 요인    | 제곱합(SS) | 자유도(df)  | 평균제곱(MS) | F     |
  | ------- | ---------- | ----------- | ------------ | ----- |
  | 집단 간 | 190        | 3 - 1 = 2   | 95.0         | 17.81 |
  | 집단 내 | 64         | 15 - 3 = 12 | 5.33         |       |
  | 전체    | 254        | 14          |              |       |

- 판단: 자유도 (2, 12), α = 0.05에서 F 기각 기준값은 약 3.89이다. 17.81은 이보다 크므로 귀무가설을 기각한다.
- 결론: 유의수준 5%에서 교수법에 따라 평균 점수에 차이가 있다고 할 수 있다.
- 사후검정: Tukey HSD로 비교하면 B는 A, C와 차이가 있고, A와 C 사이에는 유의한 차이가 없다.

```r
score  <- c(70, 72, 68, 75, 70, 78, 80, 76, 82, 79, 71, 74, 69, 73, 73)
method <- factor(rep(c("A", "B", "C"), each = 5))
result <- aov(score ~ method)
summary(result)    # 분산분석표 (Df, Sum Sq, Mean Sq, F value, Pr(>F))
TukeyHSD(result)   # 사후검정
```

### 이원분산분석(two-way ANOVA)

범주형 독립변수(요인)가 2개일 때 사용하는 분석 방법. 독립변수가 3개 이상이면 다원분산분석이라고 한다.

- 예: 비료 종류(요인 1)와 물의 양(요인 2)에 따라 식물 성장(종속변수)에 차이가 있는가

이원분산분석은 각 요인의 효과(주효과)와 함께 두 요인 사이의 **교호작용** 을 검정한다.

- 교호작용이란 한 독립변수가 종속변수에 미치는 효과가 다른 독립변수의 수준에 따라 달라지는 것을 말한다. (예: 물을 많이 주는 효과가 비료 A에서는 작지만, 비료 B에서는 크다)
- 독립변수끼리 서로 상관이 있다는 뜻이 아니라, 두 독립변수가 함께 작용할 때 종속변수에 미치는 효과가 달라진다는 뜻이다.

**`반복이 있는 실험과 반복이 없는 실험`**

| 구분             | 설명                                                                                                                                                |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 반복이 있는 실험 | 두 요인의 각 조합(예: 비료 A + 물 많이)마다 관측값이 2개 이상인 실험. 교호작용을 오차와 분리해 검정할 수 있다.                                      |
| 반복이 없는 실험 | 각 조합마다 관측값이 1개뿐인 실험. 교호작용과 오차를 분리할 수 없어 교호작용을 검정할 수 없으므로, 교호작용이 없다고 가정하고 두 주효과만 검정한다. |

- 즉, 교호작용의 유무를 확인하려면 반복이 있는 실험을 해야 한다.

**`이원분산분석 예시`**

비료 종류(F1, F2)와 물의 양(적음, 많음)에 따라 식물의 키(cm)에 차이가 있는지 확인하고 싶다. 각 조합마다 3개씩 키웠다. (반복이 있는 실험)

- 데이터

  | 비료 \ 물 | 적음       | 많음       |
  | --------- | ---------- | ---------- |
  | F1        | 20, 22, 21 | 24, 25, 23 |
  | F2        | 21, 23, 22 | 31, 30, 32 |

- 가설: 세 가지를 각각 검정한다.
  - 비료의 주효과 → H0: 비료 종류에 따른 평균 차이가 없다
  - 물의 주효과 → H0: 물의 양에 따른 평균 차이가 없다
  - 교호작용 → H0: 비료와 물 사이에 교호작용이 없다
- 계산: 조합별 평균 F1+적음 21, F1+많음 24, F2+적음 22, F2+많음 31

  | 요인      | 제곱합(SS) | 자유도(df) | 평균제곱(MS) | F   |
  | --------- | ---------- | ---------- | ------------ | --- |
  | 비료      | 48         | 1          | 48           | 48  |
  | 물        | 108        | 1          | 108          | 108 |
  | 비료 × 물 | 27         | 1          | 27           | 27  |
  | 오차      | 8          | 8          | 1            |     |
  | 전체      | 191        | 11         |              |     |

- 판단: 자유도 (1, 8), α = 0.05에서 F 기각 기준값은 약 5.32이다. 세 F값 모두 이보다 크므로 세 귀무가설을 모두 기각한다.
- 결론: 비료와 물의 양 모두 식물의 키에 영향을 주고, 교호작용도 있다. 물을 많이 주면 F1에서는 3cm(21 → 24) 커지지만 F2에서는 9cm(22 → 31) 커진다. 즉, 물의 효과가 비료 종류에 따라 다르다.

```r
height     <- c(20, 22, 21, 24, 25, 23, 21, 23, 22, 31, 30, 32)
fertilizer <- factor(rep(c("F1", "F2"), each = 6))
water      <- factor(rep(rep(c("low", "high"), each = 3), times = 2))
summary(aov(height ~ fertilizer * water))   # * 는 주효과 + 교호작용, + 는 주효과만
```

## 교차분석

### 교차분석 개요

교차분석은 범주형 자료(명목, 서열) 간의 관계를 분석할 때 사용되는 분석방법이다.

두 범주형 변수의 범주별 빈도를 행과 열로 정리한 표를 교차표(분할표, contingency table)라고 하며, 교차분석은 이 표를 바탕으로 진행한다.

카이제곱 검정통계량을 이용한다.

- 검정통계량: χ² = Σ (관측도수 - 기대도수)² / 기대도수
- 관측도수와 기대도수의 차이가 클수록 χ²값이 커지고, 귀무가설을 기각하게 된다.
- 주의: 기대도수가 5 미만인 셀이 전체 셀의 20%를 넘으면 카이제곱 검정 결과를 신뢰하기 어렵다. 이때는 피셔의 정확 검정(Fisher's exact test, R: `fisher.test()`)을 사용한다.

### 적합도 검정

실험결과 얻어진 관측값이 예상값과 일치하는지 여부를 검정하는 방법.

- 범주형 변수 1개의 분포가 이론적으로 기대하는 분포(예: 균등분포, 특정 비율)와 같은지 검정한다.
- 가설: H0: 관측된 분포가 기대 분포와 같다, H1: 다르다
- 자유도 = 범주의 수 - 1

| 용어     | 설명                                                                                          |
| -------- | --------------------------------------------------------------------------------------------- |
| 관측도수 | 실제 표본에서 각 범주에 관측된 빈도                                                           |
| 기대도수 | 귀무가설이 참일 때 각 범주에 나올 것으로 기대되는 빈도 (전체 표본 수 × 해당 범주의 기대 비율) |

**`적합도 검정 예시`**

주사위가 공정한지(각 눈이 나올 확률이 1/6로 같은지) 확인하려고 60번 던졌다.

| 눈       | 1   | 2   | 3   | 4   | 5   | 6   |
| -------- | --- | --- | --- | --- | --- | --- |
| 관측도수 | 8   | 12  | 9   | 11  | 6   | 14  |
| 기대도수 | 10  | 10  | 10  | 10  | 10  | 10  |

- 계산: χ² = (8-10)²/10 + (12-10)²/10 + ... + (14-10)²/10 = 4.2, 자유도 = 6 - 1 = 5
- 판단: 자유도 5, α = 0.05에서 χ² 기각 기준값은 약 11.07이다. 4.2는 이보다 작으므로 귀무가설을 기각하지 못한다.
- 결론: 유의수준 5%에서 주사위가 공정하지 않다고 할 근거가 부족하다.

```r
x <- c(8, 12, 9, 11, 6, 14)
chisq.test(x, p = rep(1/6, 6))   # p: 각 범주의 기대 비율
```

### 독립성 검정

모집단이 두 개의 변수에 의해 범주화됐을 때 그 두 변수들 사이의 관계가 독립적인지 아닌지 검정하는 것.

- 가설: H0: 두 변수는 서로 독립이다 (관계가 없다), H1: 두 변수는 독립이 아니다 (관계가 있다)
- 기대도수 = (해당 행의 합계 × 해당 열의 합계) / 전체 합계
- 자유도 = (행의 수 - 1) × (열의 수 - 1)

귀무가설을 기각하면 두 변수 사이에 유의미한 관계가 있다고 판단한다. 귀무가설을 기각하지 못하면 두 변수 사이에 관계가 있다고 할 근거가 부족하다고 판단한다.

카이제곱 검정에 의한 독립성 검정 결과는 변수간에 관계 유무만을 나타내며, 관계의 강도는 나타내지 않는다.

- 범주형 변수 사이의 관계의 강도는 크래머 V(Cramér's V), 파이 계수 등으로 측정한다. 크래머 V는 0 ~ 1 사이의 값을 가지며 1에 가까울수록 관계가 강하다.
- 상관분석(피어슨 상관계수)은 수치형 변수를 위한 방법이라 명목형 범주 자료에는 쓸 수 없다.

**`독립성 검정 예시`**

성별과 선호하는 상품 종류 사이에 관계가 있는지 확인하려고 120명을 조사했다.

| 성별 \ 상품 | A              | B              | C              | 합계 |
| ----------- | -------------- | -------------- | -------------- | ---- |
| 남성        | 30 (기대 22.5) | 10 (기대 17.5) | 20 (기대 20.0) | 60   |
| 여성        | 15 (기대 22.5) | 25 (기대 17.5) | 20 (기대 20.0) | 60   |
| 합계        | 45             | 35             | 40             | 120  |

- 기대도수 계산 예: 남성 × A = (60 × 45) / 120 = 22.5
- 계산: χ² ≈ 11.43, 자유도 = (2 - 1) × (3 - 1) = 2
- 판단: 자유도 2, α = 0.05에서 χ² 기각 기준값은 약 5.99이다. 11.43은 이보다 크므로 귀무가설을 기각한다.
- 결론: 유의수준 5%에서 성별과 선호 상품 사이에는 관계가 있다고 할 수 있다. (크래머 V ≈ 0.31)

```r
tbl <- matrix(c(30, 10, 20,
                15, 25, 20), nrow = 2, byrow = TRUE)
chisq.test(tbl)
```

### 동질성 검정

여러 모집단(집단)에서 각각 표본을 뽑았을 때, 한 범주형 변수의 분포(범주별 비율)가 집단마다 같은지를 검정하는 것.

- 가설: H0: 모든 집단에서 범주별 비율이 같다 (동질적이다), H1: 적어도 한 집단의 비율이 다르다
- 예: 서울, 부산, 대구에서 각각 100명씩 뽑아 지지 정당의 비율이 지역별로 같은지 검정

**`독립성 검정과 동질성 검정의 차이`**

계산 방법(기대도수, χ², 자유도)은 완전히 같고, 표본을 뽑는 방식과 질문이 다르다.

| 구분      | 독립성 검정                                  | 동질성 검정                                   |
| --------- | -------------------------------------------- | --------------------------------------------- |
| 표본 추출 | 하나의 모집단에서 표본을 뽑아 두 변수로 분류 | 여러 모집단(집단)에서 각각 표본을 뽑음        |
| 질문      | 두 변수 사이에 관계가 있는가?                | 집단마다 범주별 비율이 같은가?                |
| 합계 고정 | 전체 합계만 미리 정해짐                      | 집단별 표본 수(행 또는 열 합계)가 미리 정해짐 |

## 상관분석

### 상관분석 개념

두 변수간의 관계의 방향과 강도를 알아보는 분석 방법으로, 상관계수를 활용한다.

상관계수는 -1 ~ 1 의 범위를 갖는다. -1 또는 1에 가까울수록 상관관계가 강하다고 볼 수 있다.

- 양수면 한 변수가 커질 때 다른 변수도 커지는 양의 상관, 음수면 한 변수가 커질 때 다른 변수는 작아지는 음의 상관이다.
- 0에 가까우면 선형 관계가 거의 없다는 뜻이다. 다만 U자 모양 같은 비선형 관계는 있을 수 있으므로 산점도로 함께 확인해야 한다.
- 상관관계는 인과관계가 아니다. 아이스크림 판매량과 익사 사고 수는 양의 상관이 있지만, 둘 다 기온이라는 제3의 변수 때문에 함께 늘어날 뿐이다.

상관계수가 0인지 검정할 수도 있다.

- 가설: H0: ρ = 0 (상관관계가 없다), H1: ρ ≠ 0 (상관관계가 있다)
- 검정통계량: t = r√(n - 2) / √(1 - r²), 자유도 = n - 2 (r: 표본 상관계수, n: 표본 크기)

### 산점도 행렬(Scatterplot Matrix)

여러 변수가 있을 때 가능한 모든 변수 쌍의 산점도를 행렬 형태로 한 번에 그린 그래프이다.

- 변수 사이의 관계(선형, 비선형, 관계 없음)와 이상값을 한눈에 파악할 수 있어, 상관분석이나 회귀분석 전에 데이터를 탐색하는 용도로 쓴다.
- 대각선을 기준으로 위아래가 같은 변수 쌍을 축만 바꿔 보여주므로 대칭이다.
- R: `pairs(데이터프레임)`

### 상관분석 종류

| 종류                               | 설명                                                                                                                                        |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 피어슨 상관분석(선형적 상관관계)   | 두 연속형 변수(구간척도, 비율척도) 사이의 선형 관계를 측정한다. 모수적 방법으로 정규성을 가정하며, 이상값의 영향을 크게 받는다.             |
| 스피어만 상관분석(단조적 상관관계) | 값 대신 순위를 이용해 상관계수를 구한다. 서열척도 자료나 정규성을 만족하지 않는 자료에 쓰는 비모수적 방법이며, 이상값의 영향을 적게 받는다. |

- 스피어만 상관계수는 "한 변수가 커질 때 다른 변수도 (일정한 비율이 아니더라도) 계속 커지거나 계속 작아지는" 단조 관계를 측정한다. 모든 비선형 관계를 잡아내는 것은 아니며, U자 모양처럼 증가하다 감소하는 관계는 스피어만 상관계수로도 0에 가깝게 나온다.

**`상관분석 예시`**

공부 시간(시간)과 시험 점수 사이에 상관관계가 있는지 확인하려고 8명을 조사했다.

| 학생      | 1   | 2   | 3   | 4   | 5   | 6   | 7   | 8   |
| --------- | --- | --- | --- | --- | --- | --- | --- | --- |
| 공부 시간 | 2   | 3   | 5   | 1   | 4   | 6   | 8   | 7   |
| 시험 점수 | 65  | 70  | 78  | 60  | 72  | 85  | 92  | 80  |

- 피어슨 상관계수: r ≈ 0.966 → 매우 강한 양의 선형 관계
- 검정: t = 0.966 × √6 / √(1 - 0.966²) ≈ 9.14, 자유도 = 6. 자유도 6, α = 0.05인 양측 검정의 기각 기준은 |t| > 2.447이므로 귀무가설(ρ = 0)을 기각한다.
- 스피어만 상관계수: 공부 시간과 점수를 각각 순위로 바꿔 계산하면 ρs ≈ 0.976
- 결론: 유의수준 5%에서 공부 시간과 시험 점수 사이에는 양의 상관관계가 있다고 할 수 있다. 단, 공부 시간이 점수를 올린다는 인과관계까지 증명한 것은 아니다.

```r
hours <- c(2, 3, 5, 1, 4, 6, 8, 7)
score <- c(65, 70, 78, 60, 72, 85, 92, 80)
cor(hours, score)                            # 피어슨 상관계수 (기본값)
cor(hours, score, method = "spearman")       # 스피어만 상관계수
cor.test(hours, score, method = "pearson")   # 상관계수 검정 (t값, df, p-value 출력)
```

## 회귀분석

### 회귀분석 개념

하나 이상의 독립변수들이 종속변수에 얼마나 영향을 미치는지 추정하는 통계기법을 회귀분석이라고 한다.

독립변수가 종속변수에 영향을 미칠경우 두 변수 사이 **인과관계** 가 있다고 설명할 수 있다.

- 이와 같은 의미에서 독립변수를 원인변수(설명 변수)라고 할 수 있고, 종속변수를 결과변수(반응 변수)라고 말할 수 있다.
