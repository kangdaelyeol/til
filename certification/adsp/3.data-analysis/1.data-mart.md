## 데이터 마트의 이해

### 데이터 마트(Data Mart - DM)

데이터 마트란, 데이터 웨어하우스로부터 데이터들을 주제별, 부서별로 추출하여 모은 비교적 작은 규모의 데이터 웨어하우스를 의미한다.

### 데이터 전처리

데이터 분석에서 데이터 마트 개발 후 데이터 전처리(Preprocessing) 과정에 들어간다.

데이터 전처리는 데이터 정제(Cleansing)와 변수 처리를 포함한 포괄적인 개념이다.

**`데이터 정제 과정`**

| 과정        | 설명                                                                                                                                                                                                                                                                                |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 결측값 처리 | 값이 누락된 데이터를 그대로 두면 분석 결과가 왜곡되므로 처리 방식을 정해 보완한다. 완전 분석법(결측 레코드 삭제, 데이터 손실·편향 가능), 단순 대치법(평균·중앙값·최빈값 등으로 대체), 다중 대치법(여러 번 대치해 각각 분석한 뒤 결과를 통합)이 대표적이다.                          |
| 이상값 처리 | 다른 값들과 크게 벗어난 값(Outlier)을 탐지해 처리한다. 탐지는 ESD(평균에서 3 표준편차 이상 벗어난 값), 사분위수(Q1 - 1.5×IQR 미만 또는 Q3 + 1.5×IQR 초과), 박스플롯 등을 활용하며, 삭제·대체·변환하거나 별도로 분석한다. 사기 탐지처럼 이상값 자체가 분석 대상이면 제거하지 않는다. |

**`분석 변수 처리 과정`**

| 과정               | 설명                                                                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 변수 선택          | 분석 목적에 유의미한 변수만 골라 모델의 성능과 해석력을 높이는 과정. 필터(상관분석 등), 래퍼(전진선택·후진제거·단계적 선택), 임베디드(LASSO 등) 방식이 있다.          |
| 차원 축소          | 변수의 개수를 줄여 다중공선성과 계산 부담을 완화하는 과정. 주성분분석(PCA), 요인분석, 다차원척도법(MDS), 특이값 분해(SVD) 등을 사용한다.                              |
| 파생변수 생성      | 기존 변수를 조합하거나 함수로 가공해 새로운 의미를 갖는 변수를 만드는 과정                                                                                            |
| 변수 변환          | 분석에 적합하도록 변수의 분포나 척도를 바꾸는 과정. 로그·제곱근 변환, 정규화(Min-Max), 표준화(Z-score), 범주화(구간화), 더미변수(원-핫 인코딩) 등이 있다.             |
| 클래스 불균형 처리 | 범주별 데이터 비율이 크게 달라 소수 클래스의 예측 성능이 떨어지는 문제를 보정하는 과정. 언더샘플링, 오버샘플링(SMOTE 등), 클래스 가중치 부여, 임계값 조정을 사용한다. |

**`요약변수와 파생변수`**

| 구분     | 설명                                                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 요약변수 | 수집된 데이터를 분석 목적에 맞게 종합(집계)한 변수. 총 구매금액, 방문 횟수, 평균 구매액, 최근 구매일 등이 예이며, 여러 분석에서 재활용성이 높다.                              |
| 파생변수 | 분석가가 특정 조건이나 함수를 적용해 새로운 의미를 부여한 변수. 구매 주기, 고객 등급처럼 주관적으로 정의되므로 논리적 타당성을 갖춰야 하고, 특정 상황에서만 유의미할 수 있다. |

### 탐색적 데이터 분석(EDA, Exploratory Data Analysis)

데이터를 이해하고 의미 있는 관계를 찾아내기 위해 데이터의 통곗값과 분포 등을 시각화하고 분석하는 것

가설을 세우고 검증하는 확증적 데이터 분석(CDA)과 달리, 가설 없이 데이터 자체를 먼저 살펴보는 것이 특징이다. 존 튜키(John Tukey)가 제안했다.

**`EDA의 4가지 주제 (4R)`**

| 주제                       | 설명                                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| 저항성(Resistance)         | 일부 이상값이나 오류에 크게 영향받지 않는 성질 (예: 평균보다 중앙값) |
| 잔차 해석(Residual)        | 관측값과 모델 예측값의 차이(잔차)를 살펴 데이터의 특이점을 찾는 것   |
| 자료 재표현(Re-expression) | 로그·제곱근 변환 등으로 데이터를 해석하기 쉬운 형태로 바꾸는 것      |
| 현시성(Revelation)         | 그래프 등 시각화로 데이터의 구조와 특징을 드러내는 것                |

### 결측값

존재하지 않는 데이터를 의미하며, 일반적으로 NA(Not Available)로 표현한다. 환경에 따라서 null, 공백, -1, 999 등 다양하게 표현됨.

일반적으로 결측값은 삭제하거나 다른 값으로 대치해 처리하지만, 결측값 자체가 의미를 갖는 경우도 있다.

- 특정 설문 문항에 결측값(무응답)이 많다면, 그 문항이 응답자에게 민감한 질문이라는 지표로 활용할 수 있다.

**`결측값 대치 방법`**

| 방법             | 설명                                                                                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 완전 분석법      | 결측값이 있는 레코드를 모두 삭제하고 완전한 자료만 분석한다. 간단하지만 데이터 손실로 효율성이 떨어지고, 결측이 무작위가 아니면 결과가 편향될 수 있다.                         |
| 평균 대치법      | 관측된 자료의 평균으로 결측값을 대치한다. 비조건부 평균 대치법(관측값 전체의 평균)과 조건부 평균 대치법(회귀분석으로 예측한 값)이 있다. 표준 오차가 과소 추정되는 문제가 있다. |
| 단순 확률 대치법 | 평균 대치법의 표준 오차 과소 추정 문제를 보완하기 위해, 확률 추출로 뽑은 값으로 대치한다. Hot-deck 방법, Nearest Neighbor 방법 등이 있다.                                      |
| 다중 대치법      | 단순 대치를 한 번이 아니라 m번 반복해 m개의 완전한 자료를 만들고 각각 분석한 뒤 결과를 통합한다. 대치(Imputation) → 분석(Analysis) → 결합(Combination)의 3단계로 진행한다.     |

- 추정량 표준 오차의 과소 추정 문제: 결측값을 모두 같은 값(평균)으로 채우면 데이터의 실제 변동성이 반영되지 않아 분산이 작아진다. 그 결과 표준 오차가 실제보다 작게 추정되어 신뢰구간이 좁아지고, 유의하지 않은 결과도 유의하게 판단할 위험이 생긴다.

- K-Nearest Neighbor 방법: 결측값이 있는 관측치와 다른 변수 값이 가장 비슷한 k개의 관측치(이웃)를 찾아, 그 이웃들의 값(평균 또는 최빈값)으로 결측값을 대치한다.

### 이상값

다른 데이터와 비교했을 때 지나치게 크거나 작은 값을 이상값이라고 한다.

입력 실수처럼 잘못된 데이터일 수도 있지만, 실제로 발생한 극단적인 값일 수도 있으므로 무조건 제거하지 않고 원인에 따라 처리한다.

| 유형                                               | 처리                        |
| -------------------------------------------------- | --------------------------- |
| 의도하지 않게 잘못 입력된 경우 (입력 실수)         | 제거 대상 (Bad Data)        |
| 잘못 입력되진 않았지만 분석 목적에 맞지 않는 경우  | 제거 대상 (Bad Data)        |
| 의도하지 않은 현상이지만 분석에 포함해야 하는 경우 | 이상값으로 보고 분석에 포함 |
| 의도된 이상값 (예: 사기 거래)                      | 분석 대상 (사기 탐지 등)    |

**`이상값 판단 방법`**

| 방법                               | 설명                                                                                                                |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| ESD(Extreme Studentized Deviation) | 평균으로부터 3 표준편차 이상 떨어진 값을 이상값으로 판단한다. (μ - 3σ 미만 또는 μ + 3σ 초과)                        |
| 기하평균 활용                      | 기하평균으로부터 2.5 표준편차 이상 떨어진 값을 이상값으로 판단한다.                                                 |
| 사분위수                           | Q1 - 1.5×IQR 미만 또는 Q3 + 1.5×IQR 초과인 값을 이상값으로 판단한다. (IQR = Q3 - Q1) 박스플롯으로 시각화할 수 있다. |

- IQR(Interquartile Range): 데이터 중간 50%가 포함되는 범위, 일반적으로 Q1 ~ Q3 사이의 범위를 의미

## 통계 분석

### 통계 개요

**`표본조사`**

모집단 전체를 조사하는 것을 전수조사라고 한다. 모집단의 크기가 매우 커서 전수조사가 어려운 경우, 모집단의 일부인 표본을 추출해 조사하는 표본조사를 실시한다.

표본조사의 결과를 믿으려면 표본이 모집단의 특성을 잘 반영해야 하며, 이를 표본의 대표성이라고 한다.

- 대표성은 표본을 뽑는다고 저절로 생기지 않으므로, 적절한 표본추출 방법을 사용해 확보해야 한다.

**`표본추출 방법`**

| 방법                       | 설명                                                                                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 단순 랜덤 추출법           | 모집단의 각 원소가 동일한 확률로 선택되도록 무작위로 추출한다.                                                                                                 |
| 계통 추출법                | 모집단의 원소에 번호를 매긴 뒤, 첫 번째 원소만 무작위로 고르고 이후 일정한 간격(K)마다 추출한다. 데이터에 주기성이 있으면 편향될 수 있다.                      |
| 집락(군집, Cluster) 추출법 | 모집단을 여러 군집으로 나누고, 일부 군집을 무작위로 선택해 선택된 군집의 원소를 조사한다. 군집 내부는 이질적이고 군집 간에는 동질적인 경우에 적합하다.         |
| 층화 추출법                | 모집단을 서로 겹치지 않는 여러 층으로 나누고, 각 층에서 무작위로 추출한다. 층 내부는 동질적이고 층 간에는 이질적인 경우에 적합하다. (예: 연령대별로 나눠 추출) |

**`복원/비복원 추출`**

| 구분        | 설명                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------- |
| 복원 추출   | 추출한 원소를 다시 모집단에 넣고 다음 원소를 추출한다. 같은 원소가 여러 번 뽑힐 수 있고, 각 추출은 독립적이다. |
| 비복원 추출 | 추출한 원소를 다시 넣지 않고 다음 원소를 추출한다. 같은 원소가 중복으로 뽑히지 않는다.                         |

**`측정과 척도`**

| 구분 | 설명                                                                                   |
| ---- | -------------------------------------------------------------------------------------- |
| 측정 | 표본집단을 주어진 목적에 적합하게 관측해 자료를 얻는 것                                |
| 척도 | 관측 대상의 속성을 측정하여 그 값이 숫자로 나타나도록 일정한 규칙을 정하여 바꾸는 도구 |

**`척도의 종류`**

| 구분      | 종류            | 설명                                                                                                        |
| --------- | --------------- | ----------------------------------------------------------------------------------------------------------- |
| 질적 척도 | 명목척도        | 단순히 범주를 구분하기 위한 척도로, 순서나 크기의 의미가 없다. (예: 성별, 혈액형, 출생지)                   |
| 질적 척도 | 순서(서열) 척도 | 범주 사이에 순서(대소) 관계가 있지만, 값 사이의 간격은 의미가 없다. (예: 학년, 선호도, 만족도)              |
| 양적 척도 | 구간(등간) 척도 | 값 사이의 간격이 일정해 덧셈·뺄셈이 가능하지만, 절대적 0점이 없어 비율 계산은 의미가 없다. (예: 온도, 지수) |
| 양적 척도 | 비율척도        | 절대적 0점이 존재해 사칙연산(비율 계산 포함)이 모두 가능하다. (예: 무게, 나이, 시간, 금액)                  |

- 구간척도와 비율척도의 구분 기준은 절대적 0점의 유무이다. 0℃는 "온도가 없음"이 아니므로 20℃가 10℃의 2배라고 할 수 없지만, 0kg은 "무게가 없음"이므로 20kg은 10kg의 2배이다.

**`기술통계/추론통계`**

| 구분           | 설명                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------- |
| 기술통계       | 수집한 표본 데이터의 특성을 평균, 분산, 표준편차, 빈도, 그래프 등으로 요약·정리해 나타내는 통계    |
| 추론(추리)통계 | 표본에서 얻은 정보를 바탕으로 모집단의 특성(모수)을 추정하거나, 모집단에 대한 가설을 검정하는 통계 |

### 이산확률분포

**`이산확률변수`**

확률변수란 시행 결과에 따라 값이 확률적으로 정해지는 변수이다. 이 중 이산확률변수는 0, 1, 2, ...처럼 셀 수 있는 값만 가지는 확률변수이며, 각 값이 나올 확률을 확률질량함수(PMF)로 나타낸다.

| 종류          | 설명                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 베르누이 분포 | 결과가 성공/실패 두 가지뿐인 시행을 1번 했을 때의 분포. 성공 확률이 p이면 E(X) = p, V(X) = p(1-p) (예: 동전 1번 던지기)                     |
| 이항 분포     | 성공 확률이 p인 베르누이 시행을 n번 독립적으로 반복했을 때 성공 횟수의 분포. E(X) = np, V(X) = np(1-p)                                      |
| 기하 분포     | 성공 확률이 p인 베르누이 시행에서 처음 성공할 때까지 시행한 횟수의 분포. E(X) = 1/p (예: 처음 6이 나올 때까지 주사위 던진 횟수)             |
| 다항 분포     | 이항 분포를 결과가 3가지 이상인 경우로 확장한 분포. n번 시행했을 때 각 결과가 나온 횟수를 다룬다. (예: 주사위 n번 던지기)                   |
| 포아송 분포   | 단위 시간이나 단위 공간에서 어떤 사건이 발생하는 횟수의 분포. 평균 발생 횟수 λ로 정해지며 E(X) = V(X) = λ (예: 1시간 동안 걸려오는 전화 수) |

### 연속확률분포

**`연속확률변수`**

키, 무게, 시간처럼 일정 구간 안의 모든 실수 값을 가질 수 있는 확률변수이다. 확률은 확률밀도함수(PDF) 아래의 면적으로 구하므로, 특정한 한 점의 확률은 0이다.

| 종류          | 설명                                                                                                                                                                                                           |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 균일 분포     | 구간 [a, b] 안의 모든 값이 나올 확률(밀도)이 동일한 분포. E(X) = (a+b)/2                                                                                                                                       |
| 정규 분포     | 평균 μ를 중심으로 좌우 대칭인 종 모양의 분포로, N(μ, σ²)로 표기한다. Z = (X-μ)/σ로 변환하면 평균 0, 분산 1인 표준정규분포 N(0, 1)이 된다.                                                                      |
| t-분포        | 평균 0을 중심으로 좌우 대칭이지만 정규분포보다 꼬리가 두꺼운 분포. 모분산을 모를 때 표본평균으로 모평균을 추론하거나 두 집단의 평균을 비교(t-검정)할 때 사용한다. 자유도가 커질수록 표준정규분포에 가까워진다. |
| 카이제곱 분포 | k개의 서로 독립인 표준정규 확률변수를 각각 제곱해 더한 값의 분포(자유도 k). 0 이상의 값만 가지며 오른쪽으로 꼬리가 긴 비대칭 분포이다. 모분산 검정, 범주형 자료의 적합도·독립성 검정에 사용한다.               |
| F 분포        | 서로 독립인 두 카이제곱 확률변수를 각각의 자유도로 나눈 뒤 구한 비율의 분포. 0 이상의 값만 가지며 두 집단의 분산 비교(등분산 검정)와 분산분석(ANOVA)에 사용한다.                                               |

### 기댓값, 분산, 표준편차, 첨도와 왜도

| 개념                  | 설명                                                                                                                                                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 기댓값                | 확률변수가 가질 수 있는 각 값에 그 값이 나올 확률을 곱해 모두 더한 값으로, 확률변수의 평균을 의미한다. 이산형은 E(X) = Σx·P(x), 연속형은 E(X) = ∫x·f(x)dx                                                        |
| 분산                  | 확률변수의 값이 기댓값(평균)으로부터 얼마나 흩어져 있는지를 나타낸다. V(X) = E[(X-μ)²] = E(X²) - [E(X)]². 편차를 제곱하므로 단위가 원래 데이터 단위의 제곱이 된다.                                               |
| 표준편차              | 분산의 양의 제곱근(σ = √V(X)). 단위가 원래 데이터와 같아서 흩어진 정도를 직관적으로 해석하기 쉽다.                                                                                                               |
| 공분산(covariance)    | 두 확률변수가 함께 변하는 방향을 나타낸다. Cov(X, Y) = E[(X-μx)(Y-μy)]. 양수면 같은 방향, 음수면 반대 방향으로 변하고, 0이면 선형 관계가 없다. 값의 크기가 단위에 따라 달라지므로 관계의 강도를 비교하기 어렵다. |
| 상관계수(correlation) | 공분산을 두 변수의 표준편차의 곱으로 나눠 단위의 영향을 없앤 값. ρ = Cov(X, Y) / (σx·σy). -1 ~ 1 사이의 값을 가지며, 절댓값이 1에 가까울수록 선형 관계가 강하고 0에 가까울수록 약하다.                           |
| 첨도(kurtosis)        | 분포가 평균 주변에 얼마나 뾰족하게 몰려 있는지(꼬리가 얼마나 두꺼운지)를 나타낸다. 정규분포의 첨도는 3이며, 3을 뺀 값(초과 첨도)을 쓰면 정규분포가 0이 된다. 값이 클수록 뾰족하고 꼬리가 두껍다.                 |
| 왜도(skewness)        | 분포가 좌우로 얼마나 비대칭인지를 나타낸다. 0이면 좌우 대칭, 양수면 오른쪽 꼬리가 긴 분포, 음수면 왼쪽 꼬리가 긴 분포이다.                                                                                       |

- 기댓값과 분산의 성질: E(aX + b) = aE(X) + b, V(aX + b) = a²V(X). 모든 값에 상수 b를 더해도 흩어진 정도는 그대로이므로 분산은 변하지 않는다.

- 공분산이 0이라고 두 변수가 독립인 것은 아니다. 독립이면 공분산은 0이지만, 공분산이 0이어도 비선형 관계는 있을 수 있다.

- 왜도에 따른 평균·중앙값·최빈값의 위치

  | 왜도            | 분포 모양          | 대소 관계              |
  | --------------- | ------------------ | ---------------------- |
  | 왜도 = 0        | 좌우 대칭          | 평균 = 중앙값 = 최빈값 |
  | 왜도 > 0 (양수) | 오른쪽 꼬리가 길다 | 최빈값 < 중앙값 < 평균 |
  | 왜도 < 0 (음수) | 왼쪽 꼬리가 길다   | 평균 < 중앙값 < 최빈값 |
