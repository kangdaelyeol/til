## 회귀분석 개념

하나 이상의 독립변수들이 종속변수에 얼마나 영향을 미치는지 추정하는 통계기법을 회귀분석이라고 한다.

회귀분석은 독립변수가 종속변수에 영향을 준다는 **인과관계를 가정** 하고, 그 관계를 함수(회귀식)로 표현하는 분석이다.

- 이와 같은 의미에서 독립변수를 원인변수(설명 변수)라고 할 수 있고, 종속변수를 결과변수(반응 변수)라고 말할 수 있다.
- 주의: 회귀분석 결과가 유의하다고 해서 인과관계가 증명되는 것은 아니다. 회귀분석은 "X가 원인, Y가 결과"라는 방향을 분석자가 정하고 시작할 뿐이며, 실제 인과관계는 이론적 근거나 실험 설계로 뒷받침해야 한다.
- 상관분석과의 차이: 상관분석은 두 변수의 관계의 방향과 강도만 보고 원인·결과를 구분하지 않는다. 회귀분석은 독립변수와 종속변수를 구분하고, $X$가 1 변할 때 $Y$가 얼마나 변하는지를 추정한다.

### 회귀(Regression)의 의미

회귀(回歸)는 "원래의 상태로 되돌아간다"는 뜻으로, 여기서는 평균으로 되돌아가는 현상(평균으로의 회귀, regression toward the mean)을 말한다.

영국의 통계학자이자 유전학자인 프랜시스 골턴은 부모의 키와 자녀의 키 사이의 관계를 연구하면서 다음과 같은 경향을 발견했다.

- 부모와 자녀의 키 사이에는 선형적인 관계가 있다.
- 키가 큰 부모의 자녀는 평균보다 크지만 부모만큼 크지는 않고, 키가 작은 부모의 자녀는 평균보다 작지만 부모만큼 작지는 않다.
- 즉, 자녀의 키는 부모보다 전체 평균 쪽으로 다가가는 경향이 있다.

골턴은 이 현상을 "회귀"라고 불렀고, 이후 이런 관계를 분석하는 방법 자체가 회귀분석이라는 이름으로 굳어졌다.

### 선형회귀와 회귀식

독립변수와 종속변수의 관계를 직선(1차식)으로 나타내는 회귀분석을 선형회귀라고 한다. 독립변수가 1개면 단순선형회귀, 2개 이상이면 다중선형회귀이다.

- 단순선형회귀식

  $$
  Y = \beta_0 + \beta_1 X + \varepsilon
  $$
  - $\beta_0$: 절편 ($X$가 0일 때 $Y$의 값)
  - $\beta_1$: 기울기, 회귀계수 ($X$가 1 증가할 때 $Y$의 변화량)
  - $\varepsilon$: 오차 (회귀식으로 설명되지 않는 부분)

- 데이터의 추세(경향)를 따라 그린 직선을 추세선이라고 하며, 선형회귀식은 데이터에 가장 잘 맞는 추세선이라고 볼 수 있다.
- 최소제곱법(OLS, Ordinary Least Squares): "가장 잘 맞는 직선"을 정하는 방법. 실제값과 회귀식 예측값의 차이(잔차)를 제곱해 더한 값(SSE)이 가장 작아지도록 $\beta_0$, $\beta_1$을 구한다. ($y_i$: 실제값, $\hat{y}_i$: 예측값)

  $$
  SSE = \sum_{i}(y_i - \hat{y}_i)^2 \rightarrow \text{최소}
  $$

### 회귀분석과 예측

독립변수와 종속변수의 관계를 함수로 정의한 것을 회귀함수(회귀식)라고 한다. 회귀함수에 새로운 독립변수 값을 넣으면 종속변수 값을 예측할 수 있다. 따라서 회귀함수는 데이터를 통해 예측 혹은 분류(예: 로지스틱 회귀)하는 데이터 마이닝 알고리즘에도 사용된다.

회귀함수가 데이터를 얼마나 잘 설명하는지는 **설명력** 으로 나타내며, 결정계수($R^2$)로 측정한다.

- 결정계수

  $$
  R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}
  $$
  - 전체 변동(SST) 중 회귀식으로 설명되는 변동(SSR)의 비율이다. (SST, SSR, SSE는 분산분석의 제곱합 용어와 같다)
  - $0 \le R^2 \le 1$ 사이의 값을 가지며, 1에 가까울수록 회귀식이 데이터를 잘 설명한다.
  - 단순선형회귀에서는 $R^2$가 피어슨 상관계수의 제곱($r^2$)과 같다.

- 수정된 결정계수(Adjusted $R^2$): $R^2$는 독립변수를 추가하기만 해도 커지는 성질이 있다. 그래서 다중회귀에서는 변수 개수를 고려해 보정한 수정된 결정계수로 모델을 비교한다.

설명력이 높다고 예측력이 항상 높은 것은 아니다. $R^2$는 회귀식을 만든 데이터에 얼마나 잘 맞는지를 보여줄 뿐이라, 변수를 과하게 넣어 기존 데이터에만 지나치게 맞춘 모델(과적합)은 새로운 데이터에서 예측이 오히려 나빠질 수 있다.

### 회귀분석의 가정

선형회귀분석의 결과를 믿으려면 다음 가정을 만족해야 한다. 독립성, 등분산성, 비상관성, 정상성은 관측값 자체가 아니라 **잔차(오차)** 에 대한 가정이다.

| 종류           | 설명                                                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 선형성         | 독립변수와 종속변수의 관계가 선형(직선)이다. 산점도로 확인한다.                                                          |
| 독립성         | 잔차와 독립변수의 값이 서로 관련 없이 독립적이다.                                                                        |
| 등분산성       | 독립변수의 값과 관계없이 잔차의 분산이 일정하다. 잔차도에서 잔차가 특정한 패턴 없이 고르게 퍼져 있어야 한다.             |
| 비상관성       | 잔차끼리 서로 상관이 없다(자기상관이 없다). 더빈-왓슨(Durbin-Watson) 검정으로 확인하며, 시계열 데이터에서 특히 중요하다. |
| 정상성(정규성) | 잔차가 정규분포를 따른다. Q-Q plot이나 Shapiro-Wilk 검정(R: `shapiro.test()`)으로 확인한다.                              |

- 잔차도(residual plot): 가로축에 예측값(또는 독립변수), 세로축에 잔차를 그린 그래프. 잔차가 0을 중심으로 고르게 흩어져 있으면 선형성과 등분산성을 만족한다고 본다. 깔때기 모양처럼 퍼지는 정도가 달라지면 등분산성 위반이다.
- R에서는 `plot(lm 결과)`로 잔차도, Q-Q plot 등 진단 그래프를 한 번에 그릴 수 있다.

## 단순선형 회귀분석

독립변수와 종속변수가 1개씩일 때 둘 사이의 선형 관계를 분석하는 방법이다.

최소제곱법을 활용하여 잔차(실제값과 예측값의 차이)의 제곱합이 가장 작아지는 직선의 방정식을 찾는다.

### 최소제곱법으로 회귀계수 추정

| 방법          | 설명                                                                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 최소제곱법    | 실제 관측치와 추세선에 의해 예측된 점 사이의 거리(잔차)를 제곱하여 더한 값을 최소화 하는 것. 여기서 거리는 직선까지의 수직 거리가 아니라 $y$축 방향의 차이다. |
| 기본 알고리즘 | 최소제곱법을 활용하여 파라미터(회귀계수)를 추정하고, 추정된 파라미터를 통해 추세선을 그려 값을 예측                                                           |

- 최소제곱법으로 구한 회귀계수 ($\bar{x}$, $\bar{y}$: 각 변수의 평균)

  $$
  \hat{\beta}_1 = \frac{\sum_{i}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i}(x_i - \bar{x})^2}, \qquad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}
  $$

- 기울기는 공분산을 $x$의 분산으로 나눈 값과 같다. 그래서 기울기의 부호는 상관계수의 부호와 항상 같다.

## 회귀분석모형의 적합성

회귀분석 결과에 대한 모형 적합성을 검정하기 위해서 **분산분석표** 를 사용한다.

독립변수가 1개면 단순회귀분석, 2개 이상이면 다중회귀분석을 시행한다.

### 단순선형회귀분석 분산 분석표

| 요인 | 제곱합            | 자유도  | 평균제곱                  | F                     |
| ---- | ----------------- | ------- | ------------------------- | --------------------- |
| 회귀 | $SSR$             | $1$     | $MSR = SSR$               | $F = \frac{MSR}{MSE}$ |
| 잔차 | $SSE$             | $n - 2$ | $MSE = \frac{SSE}{n - 2}$ |                       |
| 총   | $SST = SSR + SSE$ | $n - 1$ |                           |                       |

### 다중선형회귀분석 분산 분석표

| 요인 | 제곱합            | 자유도      | 평균제곱                      | F                     |
| ---- | ----------------- | ----------- | ----------------------------- | --------------------- |
| 회귀 | $SSR$             | $k$         | $MSR = \frac{SSR}{k}$         | $F = \frac{MSR}{MSE}$ |
| 잔차 | $SSE$             | $n - k - 1$ | $MSE = \frac{SSE}{n - k - 1}$ |                       |
| 총   | $SST = SSR + SSE$ | $n - 1$     |                               |                       |

- $n$: 관측값의 수, $k$: 독립변수의 수. 단순선형회귀는 $k = 1$인 경우이다.

### 회귀모형의 통계적 유의성 검증

회귀모형의 귀무가설은 **'모든 회귀계수는 0이다'** 이며, F-검정을 통해 확인한다. (절편 $\beta_0$는 제외)

$$
H_0: \beta_1 = \beta_2 = \cdots = \beta_k = 0, \qquad H_1: \text{적어도 하나의 } \beta_i \ne 0
$$

F-검정은 두 분산의 비율을 비교할 때 사용한다. 회귀분석에서는 회귀식으로 설명되는 변동(MSR)이 설명되지 않는 변동(MSE)보다 얼마나 큰지를 비교한다.

F-통계량(F값)이 크다는 것은 잔차의 변동에 비해 회귀식으로 설명되는 변동이 크다는 의미다. 즉, 회귀모형이 종속변수를 의미 있게 설명한다고 볼 수 있다.

- 주의: F값은 회귀계수(기울기)의 크기와는 다른 개념이다. 기울기는 변수의 단위에 따라 얼마든지 커지거나 작아질 수 있지만, F값은 단위와 관계없이 설명되는 변동의 비율로 정해진다.

F값이 크면 P값(유의확률)은 상대적으로 작아진다. P값이 유의수준(보통 0.05)보다 작으면 귀무가설을 기각하고, 회귀모형이 통계적으로 유의하다고 판단한다.

- 회귀모형이 유의하다는 것은 독립변수와 종속변수 사이에 통계적으로 유의한 선형 관계가 있다는 뜻이다. 앞에서 정리한 것처럼 인과관계까지 증명하는 것은 아니다.

### 회귀계수의 통계적 유의성 검증

회귀계수의 유의성은 t-검정을 통해 확인한다. 각 회귀계수마다 따로 검정한다.

t-통계량은 회귀계수를 표준오차로 나눈 값이다. ($\hat{\beta}_i$: 추정된 회귀계수, $SE(\hat{\beta}_i)$: 회귀계수의 표준오차)

$$
H_0: \beta_i = 0, \qquad t = \frac{\hat{\beta}_i}{SE(\hat{\beta}_i)}, \qquad df = n - k - 1
$$

t-통계량의 절댓값이 크다는 것은 회귀계수가 표준오차(추정의 불확실성)에 비해 0에서 충분히 멀리 떨어져 있다는 의미다. 회귀계수 자체가 크거나, 표준오차가 작으면 t값이 커진다.

- 주의: t값이 크다고 회귀계수가 큰 것은 아니다. 회귀계수가 작아도 표준오차가 매우 작으면 t값은 커질 수 있다.

t-통계량의 절댓값이 크면 P값이 작아지고, P값이 유의수준보다 작으면 해당 독립변수가 종속변수에 유의한 영향을 준다고 판단한다.

- 단순선형회귀에서는 독립변수가 1개뿐이므로 F-검정과 기울기의 t-검정이 같은 결과를 낸다. ($F = t^2$, 두 P값도 같다)

### 모형의 설명력

회귀모형의 설명력이 좋다는 의미는 데이터가 회귀선 주변에 밀접하게 분포하고 있다는 의미다.

회귀분석 결과를 분산분석하고, 도출된 결정계수($R^2$)로 모형의 설명력을 판단한다.

결정계수($R^2$)가 1에 가깝다면 데이터들이 회귀선에 매우 밀접하게 분포한다는 것이다.

- 주의: $R^2$가 높다고 새로운 데이터에 대한 예측력도 반드시 높은 것은 아니다. $R^2$는 회귀식을 만든 데이터에 얼마나 잘 맞는지를 나타낼 뿐이다. (회귀분석과 예측 참고)

- 교재에 따라 결정계수를 $Q$로 표기하기도 한다. $Q$는 전체 데이터들의 편차를 제곱하여 합한 값(SST), $Q_e$는 잔차를 제곱하여 합한 값(SSE)이다.

  $$
  R^2 = \frac{Q - Q_e}{Q} = \frac{SST - SSE}{SST} = \frac{SSR}{SST}
  $$

## 단순선형회귀분석의 예

### 자동차 배기량과 연비 회귀분석

R에 내장된 `mtcars` 데이터(자동차 32종)로 배기량(`disp`, 세제곱인치)이 연비(`mpg`, 갤런당 마일)에 영향을 주는지 분석한다.

```r
result <- lm(mpg ~ disp, data = mtcars)   # 종속변수 ~ 독립변수
summary(result)
```

```text
F-statistic: 76.51 on 1 and 30 DF,  p-value: 9.38e-10
```

## 다중선형회귀분석

독립변수가 2개 이상이고 종속변수가 하나일 때 사용하는 회귀분석 방법으로, 독립변수와 종속변수의 관계가 선형으로 표현된다.

독립변수가 여러 개이므로 회귀계수도 여러 개다.

$$
Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_k X_k + \varepsilon
$$

- 회귀계수 $\beta_i$의 해석: 다른 독립변수들의 값이 고정되어 있을 때, $X_i$가 1 증가하면 $Y$가 $\beta_i$만큼 변한다.
- 모형의 유의성은 F-검정, 각 회귀계수의 유의성은 t-검정으로 확인한다. (회귀분석모형의 적합성 참고)
- 독립변수가 많아질수록 $R^2$는 항상 커지므로, 모형의 설명력은 수정된 결정계수로 비교한다. ($n$: 관측값의 수, $k$: 독립변수의 수)

  $$
  R^2_{adj} = 1 - \frac{(1 - R^2)(n - 1)}{n - k - 1}
  $$

### 다중공선성

다중공선성이란 회귀분석에서 독립변수 간에 강한 상관관계가 나타나는 현상이다.

다중공선성이 존재하면 각 독립변수의 영향을 따로 구분하기 어려워져, 회귀계수를 정확하게 추정할 수 없다.

- 회귀계수의 표준오차가 커진다. 그 결과 t값이 작아져서, 실제로는 중요한 변수인데도 유의하지 않게 나올 수 있다.
- 데이터가 조금만 바뀌어도 회귀계수의 값이 크게 바뀌고, 부호가 예상과 반대로 나오기도 한다.
- 모형 전체의 F-검정과 $R^2$는 높게 나오는데 개별 회귀계수는 유의하지 않다면 다중공선성을 의심해 볼 수 있다.
- 참고: 회귀분석의 가정 표에 정리한 독립성은 잔차에 대한 가정이다. 다중공선성은 독립변수끼리의 관계 문제이며, 교재에 따라 "독립변수들은 서로 독립이어야 한다"는 가정을 어긴 것으로 설명하기도 한다.

다중선형회귀분석에는 다중공선성에 유의해야 한다.

분산팽창요인(VIF, Variance Inflation Factor)을 계산하여 값이 10이 넘는다면 다중공선성이 있다고 판단할 수 있다. (기준을 5로 보기도 한다)

$$
VIF_j = \frac{1}{1 - R_j^2}
$$

- $R_j^2$는 모형 전체의 결정계수가 아니라, $j$번째 독립변수 $X_j$를 종속변수로 놓고 나머지 독립변수들로 회귀분석했을 때의 결정계수다. 즉, $X_j$가 다른 독립변수들로 얼마나 설명되는지를 나타낸다.
- $R_j^2$가 1에 가까울수록(다른 변수와 겹칠수록) VIF가 커진다. 예를 들어 $R_j^2 = 0.9$이면 $VIF_j = 10$이다.
- $1 - R_j^2$를 공차한계(tolerance)라고 하며, 0.1 미만이면 다중공선성이 있다고 본다. (VIF가 10을 넘는 것과 같은 기준)
- R: `car` 패키지의 `vif()` 함수로 계산한다.

### 다중공선성 문제 해결법

| 방법                  | 설명                                                                                                                                           |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 주성분 분석(PCA) 활용 | 서로 상관이 높은 독립변수들을 주성분 분석으로 서로 상관이 없는 새로운 변수(주성분)로 변환한 뒤, 주성분을 독립변수로 회귀분석한다(주성분 회귀). |
| 변수 제거             | VIF가 높은 변수 중 분석 목적상 덜 중요한 변수를 모형에서 제외한다.                                                                             |
| 릿지 회귀(Ridge)      | 회귀계수에 벌점(penalty)을 주어 계수가 지나치게 커지지 않도록 추정하는 방법으로, 다중공선성이 있어도 추정이 안정적이다.                        |

- 주성분 분석은 다중공선성을 없앨 수 있지만, 주성분은 원래 변수들을 섞은 값이라 회귀계수를 "배기량이 1 커지면 연비가 얼마 변한다"처럼 직관적으로 해석하기 어렵다는 단점이 있다.

### 다중선형회귀분석의 예

단순선형회귀분석의 예에 차량 무게(`wt`, 1000파운드)를 독립변수로 추가해, 배기량과 무게가 연비에 미치는 영향을 함께 분석한다.

```r
result2 <- lm(mpg ~ disp + wt, data = mtcars)
summary(result2)
library(car)
vif(result2)   # 다중공선성 확인
```

`summary()` 출력의 주요 부분

```text
Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept) 34.96055    2.16454  16.151 4.91e-16 ***
disp        -0.01773    0.00919  -1.929  0.06362 .
wt          -3.35082    1.16413  -2.878  0.00743 **

Residual standard error: 2.917 on 29 degrees of freedom
Multiple R-squared:  0.7809,	Adjusted R-squared:  0.7658
F-statistic: 51.69 on 2 and 29 DF,  p-value: 2.744e-10
```

- 회귀식: $\hat{y} = 34.96 - 0.0177 \times \text{disp} - 3.351 \times \text{wt}$
- 모형의 유의성: $F = 51.69$, p-value $< 0.05$이므로 회귀모형은 유의하다.
- 설명력: 수정된 결정계수가 단순회귀의 0.709에서 0.7658로 올라갔다. 무게를 추가해 설명력이 좋아졌다.
- 회귀계수의 유의성
  - `wt`: p-value $= 0.00743 < 0.05$ → 유의하다. 배기량이 같을 때 무게가 1000파운드 늘면 연비가 약 3.35마일/갤런 낮아진다.
  - `disp`: p-value $= 0.0636 > 0.05$ → 유의하지 않다. 단순회귀에서는 매우 유의했던($9.38 \times 10^{-10}$) 배기량이, 무게와 함께 넣으니 유의하지 않게 되었다.
- 다중공선성: 배기량과 무게의 상관계수는 약 0.888로 매우 높다. 배기량이 큰 차는 대체로 무겁기 때문에, 두 변수가 연비에 주는 영향이 겹쳐 배기량만의 효과를 따로 구분하기 어려워진 것이다.
  - 독립변수가 2개이면 $R_j^2$는 두 변수 상관계수의 제곱이므로 $VIF = \frac{1}{1 - 0.888^2} \approx 4.73$이다. 10보다는 작지만, 기준을 5로 보면 경계에 가까운 수준이다.

## 최적 회귀방정식

1개의 반응변수 $y$를 설명하기 위한 $k$개의 독립변수 후보들이 있을 때, 반응변수 $y$를 가장 잘 설명할 수 있는 회귀식을 최적 회귀방정식이라고 한다.

종속변수에 유의미한 영향을 미칠 것으로 생각되는 독립변수만 선택해 회귀식을 만든다. 불필요한 변수를 빼면 모형이 단순해져 해석하기 쉽고, 과적합이 줄어 예측 성능도 좋아진다.

### 변수선택법 구분

| 방법              | 설명                                                                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 부분집합법        | 독립변수로 만들 수 있는 모든 조합($2^k$개)의 회귀모형을 만들어 비교하고 가장 좋은 모형을 고른다. 가장 확실하지만 변수가 많으면 계산량이 매우 커진다. |
| 단계적 변수선택법 | 일정한 기준(p-value, AIC 등)에 따라 변수를 하나씩 추가하거나 제거하면서 최적의 모형을 찾는다. 모든 조합을 보지 않으므로 계산이 빠르다.               |

- 예: 독립변수 후보가 10개면 부분집합법은 $2^{10} = 1024$개의 모형을 비교해야 한다.

### 변수선택법 작동 원리에 따른 분류

| 분류               | 설명                                                                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 필터(Filter)       | 모델을 학습하기 전에 상관계수, 카이제곱 통계량 같은 통계적 지표로 변수와 종속변수의 관계를 평가해 미리 변수를 고른다. 빠르지만 변수 사이의 조합 효과는 보지 못한다.   |
| 래퍼(Wrapper)      | 변수 조합을 바꿔 가며 실제로 모델을 학습시키고, 그 성능을 기준으로 변수를 고른다. 전진 선택법, 후진 제거법, 단계별 방법이 여기에 속한다. 정확하지만 계산 비용이 크다. |
| 임베디드(Embedded) | 모델을 학습하는 과정 안에서 변수 선택이 함께 이루어진다. 라쏘(LASSO)는 중요하지 않은 변수의 회귀계수를 0으로 만들어 자동으로 변수를 제거한다.                         |

### 변수 선택에 사용되는 지표

회귀모형은 변수의 수가 증가할 수록 편향(bias)은 작아지고 분산은 커지려는 경향이 있다.

- 편향: 모형이 너무 단순해서 실제 관계를 제대로 표현하지 못하는 정도
- 분산: 학습 데이터가 조금만 바뀌어도 모형이 크게 달라지는 정도 (과적합과 관련)

따라서 변수의 수가 많아 복잡해진 모형에는 벌점(penalty)을 주어 최적 회귀방정식을 도출한다.

세 지표 모두 **값이 작을수록 좋은 모형** 이다.

| 지표                                | 설명                                                                                                                                                     |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AIC(Akaike Information Criterion)   | 모형의 적합도(우도)에 변수 개수만큼 벌점을 더한 값. R의 `step()` 함수가 기본으로 사용하는 기준이다.                                                      |
| BIC(Bayesian Information Criterion) | AIC와 같은 구조지만 벌점에 표본 크기 $n$이 반영되어, 표본이 커질수록 AIC보다 벌점이 커진다. 그래서 AIC보다 변수가 적은 단순한 모형을 고르는 경향이 있다. |
| 멜로우즈 Cp(Mallows' Cp)            | 최소자승법으로 추정한 회귀모형의 오차를 바탕으로 계산하며, 좋은 모형일수록 $C_p$가 작고 회귀계수의 개수 $p$에 가깝다.                                    |

- 계산식 ($L$: 모형의 최대 우도, $p$: 절편을 포함한 회귀계수의 개수, $n$: 표본 크기, $SSE_p$: 해당 모형의 잔차제곱합, $MSE_{full}$: 모든 변수를 넣은 모형의 평균제곱오차)

  $$
  AIC = -2\ln L + 2p, \qquad BIC = -2\ln L + p\ln n, \qquad C_p = \frac{SSE_p}{MSE_{full}} - (n - 2p)
  $$

- AIC의 벌점은 변수 하나당 2, BIC의 벌점은 변수 하나당 $\ln n$이다. $n \ge 8$이면 $\ln n > 2$이므로 BIC의 벌점이 더 크다.

### 단계적 변수 선택법 종류

| 종류                              | 설명                                                                                                                                                                            |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 전진 선택법(Forward selection)    | 상수항(절편)만 있는 모형에서 시작해, 종속변수를 가장 잘 설명하는(가장 유의한) 변수를 하나씩 추가한다. 더 이상 유의한 변수가 없으면 멈춘다. 한 번 추가된 변수는 제거되지 않는다. |
| 후진 제거법(Backward elimination) | 모든 독립변수를 넣은 모형에서 시작해, 가장 덜 유의한 변수를 하나씩 제거한다. 모든 변수가 유의해지면 멈춘다. 한 번 제거된 변수는 다시 추가되지 않는다.                           |
| 단계별 방법(Stepwise method)      | 전진 선택법처럼 변수를 하나씩 추가하되, 매 단계마다 이미 들어간 변수 중 유의성이 떨어진 변수가 있으면 제거한다. 전진 선택법과 후진 제거법의 단점을 보완한 방법이다.             |

- 전진 선택법은 계산이 빠르지만 한 번 들어간 변수를 다시 검토하지 않는다. 후진 제거법은 모든 변수를 함께 보고 시작하지만, 변수가 많으면 시작 모형이 복잡하다.
- R: `step()` 함수로 실행하며, AIC가 가장 작아지는 방향으로 변수를 추가하거나 제거한다.

```r
full  <- lm(mpg ~ ., data = mtcars)   # 모든 변수를 넣은 모형
empty <- lm(mpg ~ 1, data = mtcars)   # 상수항만 있는 모형
step(full, direction = "backward")                                  # 후진 제거법
step(empty, scope = formula(full), direction = "forward")           # 전진 선택법
step(empty, scope = formula(full), direction = "both")              # 단계별 방법
```

### 과적합과 과소적합

| 구분                   | 설명                                                                                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 과적합(Overfitting)    | 모형이 학습 데이터에 지나치게 맞춰져, 데이터의 우연한 잡음(noise)까지 학습한 상태. 학습 데이터에서는 오차가 매우 작지만 새로운 데이터에서는 예측 성능이 크게 떨어진다. 분산이 큰 상태이다. |
| 과소적합(Underfitting) | 모형이 너무 단순해서 데이터의 패턴을 제대로 학습하지 못한 상태. 학습 데이터와 새로운 데이터 모두에서 오차가 크다. 편향이 큰 상태이다.                                                      |

- 과적합의 원인: 변수가 너무 많거나, 모형이 너무 복잡하거나, 데이터가 부족한 경우
- 과적합의 해결: 불필요한 변수 제거(변수선택법), 정규화(규제), 데이터 추가, 교차검증으로 모형 평가
- 과소적합의 해결: 변수를 추가하거나 더 복잡한 모형을 사용한다.

### 정규화 선형회귀 종류

회귀분석에서 과적합되면 계수의 크기도 과도하게 증가하는 경향이 있다. 이를 방지하기 위해 계수의 크기를 제한하는 방법을 사용한다. 이를 정규화 선형회귀라고 한다.

- 일반 선형회귀(최소제곱법)는 잔차제곱합(SSE)만 최소화한다. 정규화 선형회귀는 SSE에 **회귀계수의 크기에 대한 벌점(penalty)** 을 더한 값을 최소화한다. 그래서 회귀계수가 커질수록 손해를 보게 되어, 계수가 0 쪽으로 줄어든다.
- 벌점의 세기는 $\lambda$(람다)로 조절한다. $\lambda = 0$이면 일반 선형회귀와 같고, $\lambda$가 클수록 계수가 더 많이 줄어든다. 적절한 $\lambda$는 교차검증으로 정한다.
- 여기서 정규화는 규제(regularization)를 뜻한다. 데이터의 척도를 맞추는 정규화(normalization)나 정규분포의 정규성과는 다른 개념이다.
- 벌점이 계수의 크기에 걸리므로, 변수들의 단위가 다르면 결과가 왜곡된다. 그래서 보통 변수를 표준화한 뒤 적용한다.

| 종류                    | 설명                                                                                                                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 라쏘(Lasso regression)  | 회귀계수의 절댓값의 합($L_1$ 노름)을 벌점으로 사용한다. 중요하지 않은 변수의 회귀계수를 정확히 0으로 만들 수 있어, 변수 선택 효과가 있다.                                                  |
| 릿지(Ridge regression)  | 회귀계수의 제곱의 합($L_2$ 노름)을 벌점으로 사용한다. 계수를 0에 가깝게 줄이지만 정확히 0으로 만들지는 않으므로 변수가 제거되지 않는다. 다중공선성이 있을 때도 계수를 안정적으로 추정한다. |
| 엘라스틱넷(Elastic net) | 라쏘의 $L_1$ 벌점과 릿지의 $L_2$ 벌점을 함께 사용한다. 변수 선택 효과와 안정적인 추정을 함께 얻을 수 있고, 서로 상관이 높은 변수들을 묶어서 함께 선택하거나 제거하는 경향이 있다.          |

- 각 방법이 최소화하는 값 ($y_i$: 실제값, $\hat{y}_i$: 예측값, $\beta_j$: 회귀계수, 절편은 벌점에서 제외)

  $$
  \begin{aligned}
  \text{라쏘} &: \quad \sum_{i}(y_i - \hat{y}_i)^2 + \lambda \sum_{j} \lvert \beta_j \rvert \\
  \text{릿지} &: \quad \sum_{i}(y_i - \hat{y}_i)^2 + \lambda \sum_{j} \beta_j^2 \\
  \text{엘라스틱넷} &: \quad \sum_{i}(y_i - \hat{y}_i)^2 + \lambda_1 \sum_{j} \lvert \beta_j \rvert + \lambda_2 \sum_{j} \beta_j^2
  \end{aligned}
  $$

- 시험 포인트: 변수 선택(계수를 0으로 만듦)이 가능한 것은 라쏘, 다중공선성 문제에 주로 쓰는 것은 릿지이다.
- R: `glmnet` 패키지의 `glmnet()` 함수를 사용하며, `alpha` 값으로 방법을 고른다.

```r
library(glmnet)
x <- as.matrix(mtcars[, -1])   # 독립변수 (mpg 제외)
y <- mtcars$mpg                # 종속변수
glmnet(x, y, alpha = 1)        # 라쏘
glmnet(x, y, alpha = 0)        # 릿지
glmnet(x, y, alpha = 0.5)      # 엘라스틱넷 (0과 1 사이)
cv.glmnet(x, y, alpha = 1)     # 교차검증으로 최적의 λ 찾기
```

## 일반화 선형회귀(GLM, Generalized Linear Model)

회귀분석을 진행하려고 할 때 종속변수가 범주형 자료이거나 정규성을 만족하지 못하는 경우, 종속변수의 기댓값을 적절한 함수(연결 함수)로 변환한 다음 이 값과 독립변수의 선형 결합을 연결하여 회귀분석을 수행한다. 이를 일반화 선형회귀라고 한다.

- 일반 선형회귀는 종속변수가 정규분포를 따르는 연속형 변수라고 가정한다. 일반화 선형회귀는 이 가정을 넓혀, 이항분포나 포아송분포처럼 정규분포가 아닌 분포를 따르는 종속변수도 다룰 수 있게 한 것이다.
- 예: 합격/불합격(범주형), 하루 방문자 수(0 이상의 정수)
- 회귀계수는 최소제곱법이 아니라 최대우도법(MLE)으로 추정한다.

### 일반화 선형회귀 구성요소

| 요소                          | 설명                                                                                                             |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 확률 요소(Random Component)   | 종속변수 $Y$가 따르는 확률분포. 정규분포, 이항분포, 포아송분포 등 지수족(exponential family) 분포 중에서 정한다. |
| 선형 예측자(Linear Predictor) | 독립변수들의 선형 결합. $\eta = \beta_0 + \beta_1 X_1 + \cdots + \beta_k X_k$                                    |
| 연결 함수(Link function)      | 종속변수의 기댓값 $E(Y)$와 선형 예측자 $\eta$를 연결하는 함수. $g(E(Y)) = \eta$를 만족한다.                      |

- 종속변수의 분포에 따른 연결 함수

  | 종속변수의 분포 | 연결 함수                                         | 회귀모형      |
  | --------------- | ------------------------------------------------- | ------------- |
  | 정규분포        | 항등 함수: $g(\mu) = \mu$                         | 일반 선형회귀 |
  | 이항분포        | 로짓 함수: $g(p) = \ln\left(\frac{p}{1-p}\right)$ | 로지스틱 회귀 |
  | 포아송분포      | 로그 함수: $g(\lambda) = \ln \lambda$             | 포아송 회귀   |

- 일반 선형회귀도 연결 함수가 항등 함수인 일반화 선형회귀의 한 종류라고 볼 수 있다.

### 일반화 선형회귀의 종류

| 종류                               | 설명                                                                                                                                                                                                |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 로지스틱 회귀(Logistic regression) | 종속변수가 범주형(주로 성공/실패처럼 두 가지)일 때 사용한다. 사건이 일어날 확률을 0 ~ 1 사이 값으로 예측하고, 기준값(보통 0.5)보다 크면 1, 작으면 0으로 분류한다. 연결 함수로 로짓 함수를 사용한다. |
| 포아송 회귀(Poisson regression)    | 종속변수가 일정 시간이나 공간에서 사건이 발생한 횟수(0 이상의 정수)일 때 사용한다. 연결 함수로 로그 함수를 사용한다. (예: 하루 동안의 고객 방문 수, 한 달간의 사고 건수)                            |

**`로지스틱 회귀`**

- 모형 ($p$: 사건이 일어날 확률)

  $$
  \ln\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 X_1 + \cdots + \beta_k X_k
  $$

- 오즈(odds): $\frac{p}{1-p}$. 사건이 일어날 확률이 일어나지 않을 확률의 몇 배인지를 나타낸다. (예: $p = 0.8$이면 오즈는 4)
- 회귀계수의 해석: $X_i$가 1 증가하면 오즈가 $e^{\beta_i}$배가 된다. $e^{\beta_i}$를 오즈비(odds ratio)라고 한다.
- 위 식을 $p$에 대해 풀면 다음과 같은 S자 모양의 곡선(시그모이드 함수)이 되어, 예측값이 항상 0 ~ 1 사이에 있다.

  $$
  p = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \cdots + \beta_k X_k)}}
  $$

**`포아송 회귀`**

- 모형 ($\lambda$: 사건의 평균 발생 횟수)

  $$
  \ln \lambda = \beta_0 + \beta_1 X_1 + \cdots + \beta_k X_k
  $$

- 회귀계수의 해석: $X_i$가 1 증가하면 평균 발생 횟수가 $e^{\beta_i}$배가 된다.
- 포아송분포는 평균과 분산이 같다고 가정한다($E(Y) = V(Y) = \lambda$). 실제 데이터의 분산이 평균보다 훨씬 크면(과대산포) 음이항 회귀 등을 사용한다.

```r
glm(am ~ wt, data = mtcars, family = binomial)   # 로지스틱 회귀 (am: 변속기 종류 0/1)
glm(y ~ x, data = df, family = poisson)          # 포아송 회귀 (y: 발생 횟수)
```

## 더빈 왓슨(Durbin-Watson) 검정

오차항이 서로 상관관계를 갖는 경우는 대부분 시계열 데이터의 경우다.

**`시계열 데이터`**

시계열 데이터는 시간의 흐름대로 나열된 데이터를 말한다. (예: 일별 주가, 월별 매출)

시계열 데이터들은 연속적인 일련의 관측치들이 서로 상관되어 있다. 이를 **자기 상관성** 이라고 한다.

- 예: 오늘 주가는 어제 주가와 비슷한 경우가 많다. 이처럼 바로 앞 시점의 값이 다음 시점의 값에 영향을 준다.

### 더빈 왓슨 검정

회귀분석에 있어서는 오차항이 서로 연관성이 없어야 한다. 즉, 회귀분석에서의 서로 다른 오차항의 공분산은 0이다. (회귀분석의 가정 중 비상관성)

$$
\mathrm{Cov}(\varepsilon_i, \varepsilon_j) = 0 \quad (i \ne j)
$$

오차항끼리 자기 상관성이 있으면 회귀계수의 표준오차가 실제보다 작게 추정되어, t-검정과 F-검정 결과를 신뢰할 수 없다. 이 경우 시계열 분석 등 자기상관을 고려하는 다른 분석 방법을 사용해야 한다.

더빈 왓슨 검정을 통해 오차항에 자기상관성이 존재하는지 검정한다.

- 가설: $H_0$: 오차항에 자기상관이 없다, $H_1$: 오차항에 자기상관이 있다
- 검정통계량 ($e_t$: $t$번째 잔차, $n$: 관측값의 수)

  $$
  d = \frac{\sum_{t=2}^{n}(e_t - e_{t-1})^2}{\sum_{t=1}^{n} e_t^2}
  $$

- 통계량 값은 $0 \le d \le 4$ 범위를 가진다. 2에 가까울수록 오차항의 자기상관이 없다는 것이다. 0에 가까우면 양의 자기상관, 4에 가까우면 음의 자기상관이 있다고 판단한다.

  | $d$ 값     | 판단                                                 |
  | ---------- | ---------------------------------------------------- |
  | 0에 가까움 | 양의 자기상관 (이웃한 잔차가 비슷한 방향으로 움직임) |
  | 2에 가까움 | 자기상관 없음                                        |
  | 4에 가까움 | 음의 자기상관 (이웃한 잔차가 번갈아 반대로 움직임)   |

- 정확한 판단은 표본 크기와 독립변수의 수에 따라 정해지는 하한값($d_L$)과 상한값($d_U$)을 기준으로 한다. 시험에서는 "2에 가까우면 자기상관 없음"을 기억하면 된다.
- R: `lmtest` 패키지의 `dwtest()` 함수로 검정한다.

```r
library(lmtest)
dwtest(lm(mpg ~ wt, data = mtcars))   # p-value > 0.05이면 자기상관이 없다고 판단
```
