## 데이터 마이닝 개요

### 데이터마이닝 이해

데이터 마이닝은 대용량 데이터 속에서 숨겨진 규칙, 패턴, 관계 등을 찾아내어 예측하거나 의사결정에 활용하는 것을 목적으로 한다.

- 예: 고객의 구매 이력으로 이탈할 고객을 예측하기, 함께 잘 팔리는 상품 조합 찾기, 비슷한 고객끼리 묶어 마케팅 전략 세우기

**`통계분석과의 차이`**

통계분석은 표본을 통해 의미 있는 정보를 추출하고, 이를 기반으로 의사결정, 연관성 파악, 예측 등의 결과로 이어지도록 하는 일련의 과정을 말한다.

통계학은 표본이 있어야 한다는 것과, 그 표본을 통해 모집단의 특성을 추론한다는 것이 중요하다. 이 통계적 추론은 **추정**(모수의 값을 짐작)과 **가설검정**(가설이 맞는지 판단)으로 이루어진다.

데이터 마이닝은 미리 가설을 세우고 검정하는 과정 없이도, 데이터 속에서 숨겨진 규칙이나 패턴을 찾아 예측이나 설명을 할 수 있다.

- 단, 가설검정을 하지 않는다고 결과를 그대로 믿는 것은 아니다. 찾아낸 모형이 새로운 데이터에서도 맞는지 별도의 데이터(검증·테스트 데이터)로 확인하는 **검증 단계**를 반드시 거친다.

| 구분      | 통계분석                                 | 데이터 마이닝                                  |
| --------- | ---------------------------------------- | ---------------------------------------------- |
| 데이터    | 표본 중심                                | 대용량 데이터(전체 데이터에 가까운 자료)       |
| 접근 방식 | 가설을 세우고 검정한다 (가설 주도)       | 데이터에서 패턴을 찾는다 (데이터 주도)         |
| 주요 관심 | 모집단의 특성 추론, 결과의 통계적 유의성 | 예측 정확도, 활용 가능한 패턴 발견             |
| 검증 방법 | p-값, 신뢰구간                           | 검증·테스트 데이터에서의 성능(정확도, 오차 등) |

데이터 마이닝은 데이터에서 인사이트(예측과 설명)를 얻는 과정으로 이해하면 좋다. 데이터 마이닝의 궁극적인 목적은 인사이트를 얻어 이를 의사결정에 활용하는 데 있다.

### 데이터 마이닝 종류

**`분석 방법에 따른 분류`**

| 분류        | 설명                                                                                                                                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 지도 학습   | 정답(목표변수, 레이블)이 있는 데이터로 학습해, 새로운 데이터의 정답을 예측하는 방법. 목표변수가 연속형이면 회귀, 범주형이면 분류 문제다. 예: 과거 고객의 이탈 여부(정답)를 학습해 신규 고객의 이탈 예측 |
| 비지도 학습 | 정답이 없는 데이터에서 데이터 자체의 구조나 패턴을 찾는 방법. 예: 구매 패턴이 비슷한 고객끼리 묶기(군집), 함께 구매되는 상품 찾기(연관)                                                                 |

**`분석 방법`**

| 구분        | 문제         | 방법 종류                                                                                                                                                                                |
| ----------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 지도학습    | 회귀(연속형) | 선형회귀분석(Linear Regression)<br>Ridge, Lasso(정규화 선형회귀)<br>의사결정나무(회귀트리모형)<br>SVR(Support Vector Regression)<br>신경망 모형                                          |
| 지도학습    | 분류(범주형) | 로지스틱회귀분석<br>의사결정나무(분류트리모형)<br>k-NN(k-최근접 이웃 알고리즘)<br>SVM(Support Vector Machine)<br>나이브 베이즈 분류<br>신경망 모형<br>앙상블 모형<br>LDA(선형 판별 분석) |
| 비지도 학습 | 군집         | 계층적 군집(병합·분할)<br>K-means<br>DBSCAN(밀도 기반 군집)<br>SOM(자기조직화지도)<br>혼합 분포 군집                                                                                     |
| 비지도 학습 | 연관         | Apriori<br>FP-Growth                                                                                                                                                                     |
| 비지도 학습 | 차원축소     | PCA(주성분 분석)<br>SVD(특잇값 분해)<br>MDS(다차원 척도법)                                                                                                                               |

- LDA(선형 판별 분석)는 정답(범주) 정보를 사용하므로 **지도학습**이다. 범주를 가장 잘 구분하는 방향으로 차원을 줄이기 때문에 차원축소에도 쓰이지만, 비지도 학습인 PCA와는 다르다.
- 병합 군집은 계층적 군집의 한 방식(하나씩 합쳐 나가는 상향식)이라 계층적 군집으로 묶었다. 반대로 전체에서 나눠 가는 하향식은 분할 군집이다.
- 의사결정나무, 신경망, k-NN, 앙상블(랜덤 포레스트 등)은 회귀와 분류 모두에 사용할 수 있다.

**`분석 목적에 따른 분류`**

| 분류                      | 설명                                                                                                                                                                   |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 분류(Classification) 분석 | 미리 정해진 범주(정답)가 있는 데이터로 모형을 만들어, 새로운 데이터가 어느 범주에 속할지 예측한다. 지도학습이다. 예: 스팸 메일 분류, 대출 연체 여부 예측               |
| 군집(Clustering) 분석     | 미리 정해진 범주 없이, 비슷한 특성을 가진 객체끼리 그룹으로 묶는다. 비지도학습이다. 그룹의 의미는 분석 후 사람이 해석한다. 예: 구매 패턴에 따른 고객 세분화            |
| 연관(Association) 분석    | 함께 발생하는 사건이나 항목 사이의 규칙("A를 사면 B도 산다")을 찾는다. 비지도학습이다. 장바구니 분석이라고도 한다. 예: 기저귀를 사는 고객이 맥주도 함께 사는 경향 발견 |

- 분류와 군집의 차이: 분류는 범주(정답)가 미리 정해져 있고, 군집은 범주 없이 데이터를 보고 그룹을 만든다.
- ADsP 교재에서는 데이터 마이닝의 기능을 분류(Classification), 추정(Estimation), 예측(Prediction), 연관 분석(Association), 군집(Clustering), 기술(Description)의 6가지로 나누기도 한다. 이 중 분류·추정·예측은 목표변수가 있는 지도학습, 연관·군집·기술은 목표변수가 없는 비지도학습에 해당한다.

### 데이터 마이닝 프로세스

| 단계                         | 설명                                                                                                                                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 목적 정의 단계               | 데이터 마이닝으로 무엇을, 왜 하려는지 분명하게 정한다. 이해관계자가 모두 동의할 수 있는 목적이어야 하며, 이 단계부터 데이터 마이닝 전문가가 참여해 어떤 기법을 쓸지도 미리 정하는 것이 좋다.   |
| 데이터 준비 단계             | 고객 정보, 거래 정보, 상품 정보 등 분석에 필요한 데이터를 수집하고, 데이터 정제(Cleansing)로 품질을 확보한다. 필요하면 외부 데이터를 보강한다. 대용량 데이터라 IT 부서와의 협의가 필요하다.    |
| 데이터 가공 단계             | 목표변수를 정의하고, 수집한 데이터를 분석 기법과 소프트웨어에 적용할 수 있는 형태로 가공한다. 파생변수 생성, 변수 변환, 학습·검증 데이터 분할 등이 이 단계에서 이루어진다.                     |
| 데이터 마이닝 기법 적용 단계 | 목적에 맞는 기법을 선택해 모형을 만든다. 기법과 소프트웨어의 매개변수(파라미터)를 조정해 가며 원하는 결과를 얻는다. 데이터 분석 전문가의 전문성이 필요한 단계다.                               |
| 검증 단계                    | 만들어진 모형의 결과를 검증 데이터나 과거 데이터로 확인하고, 실제 업무에 적용했을 때 얻는 효과(추가 수익, 투자 대비 효과(ROI) 등)를 평가한다. 검증된 모형은 업무에 적용하고 보고서로 정리한다. |

- 각 단계는 한 번에 끝나지 않는다. 검증 결과가 나쁘면 데이터 준비나 가공 단계로 돌아가 다시 진행한다.

### 데이터 분할

데이터 마이닝 기법을 적용하기 위해 데이터셋을 훈련용, 검증용, 평가용의 세 가지 데이터로 분할한다.

모형을 만든 데이터로 성능까지 평가하면, 이미 본 문제로 시험을 치르는 것과 같아 성능이 실제보다 좋게 나온다. 그래서 모형이 **처음 보는 데이터**에서도 잘 맞는지(일반화 성능) 확인하기 위해 데이터를 나눈다.

- 교재에 따라 Validation을 "검정용"으로 쓰기도 한다. 가설검정의 "검정"과 헷갈리지 않도록 이 노트에서는 "검증용"으로 쓴다.

**`데이터셋 분할`**

| 분류                        | 목적                           | 설명                                                                                                                                                                                           |
| --------------------------- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 훈련용(Train) 데이터셋      | 모형 학습                      | 모형이 데이터의 패턴을 학습하는 데 사용한다. 모형의 파라미터(회귀계수, 가중치 등)가 이 데이터로 추정된다. 가장 많은 비율을 차지한다.                                                           |
| 검증용(Validation) 데이터셋 | 모형 선택, 하이퍼파라미터 조정 | 학습 중인 모형의 성능을 중간 점검하는 데 사용한다. 여러 모형이나 하이퍼파라미터 값을 비교해 가장 좋은 것을 고르고, 과적합 여부를 확인한다. 학습에는 직접 사용하지 않는다.                      |
| 평가용(Test) 데이터셋       | 최종 성능 평가                 | 모형을 완성한 뒤 **마지막에 한 번만** 사용해 일반화 성능을 평가한다. 학습이나 모형 선택 과정에 전혀 사용하지 않아야 한다. 평가 결과를 보고 모형을 다시 고치면 평가용 데이터의 의미가 사라진다. |

- 비유: 훈련용은 교과서, 검증용은 모의고사(공부 방법을 바꿔 가며 점검), 평가용은 실제 시험이다.
- 분할 비율은 정해져 있지 않다. 흔히 6:2:2, 7:1.5:1.5를 사용하며, ADsP 교재에는 50%(훈련용), 30%(검증용), 20%(평가용)의 예가 나오기도 한다.
- 데이터가 적어 세 개로 나누기 어렵다면, 훈련용과 평가용으로만 나누고 검증은 아래의 교차검증으로 대신한다.
- 데이터 누수(Data Leakage) 주의: 평가용 데이터의 정보가 학습 과정에 섞이면 안 된다. 예를 들어 표준화를 할 때 평균과 표준편차는 훈련용 데이터로만 계산하고, 그 값을 검증용·평가용 데이터에 그대로 적용한다.

**`파라미터 분류`**

| 분류           | 설명                                                                                                                                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 파라미터       | 모형이 훈련용 데이터로 학습하면서 **스스로 추정하는 값**. 사람이 직접 정하지 않는다. 예: 회귀분석의 회귀계수($\beta$), 신경망의 가중치와 편향, 로지스틱 회귀의 계수                                                                                    |
| 하이퍼파라미터 | 학습을 시작하기 전에 **분석가가 직접 정하는 값**. 데이터로 학습되지 않으므로 검증용 데이터나 교차검증으로 여러 값을 비교해 정한다. 예: k-NN의 $k$, 의사결정나무의 최대 깊이, Lasso·Ridge의 $\lambda$, K-means의 군집 수 $K$, 신경망의 학습률·은닉층 수 |

- 하이퍼파라미터 값을 여러 개 시도해 보며 가장 좋은 조합을 찾는 것을 하이퍼파라미터 튜닝이라고 한다. 후보를 모두 시도하는 그리드 서치(Grid Search), 무작위로 골라 시도하는 랜덤 서치(Random Search) 등이 있다.

### 과적합 과소적합 관련 데이터 분할을 통한 검증 방법

| 구분                   | 설명                                                                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 과적합(Overfitting)    | 모형이 훈련용 데이터에 지나치게 맞춰져, 훈련용 데이터의 우연한 잡음까지 외워 버린 상태. 훈련용 데이터에서는 성능이 좋지만 새로운 데이터에서는 성능이 떨어진다. |
| 과소적합(Underfitting) | 모형이 너무 단순해 데이터의 패턴을 충분히 학습하지 못한 상태. 훈련용 데이터에서도 성능이 낮다.                                                                 |

- 비유: 과적합은 기출문제 답만 외워 새로운 문제를 못 푸는 상태, 과소적합은 공부를 덜 해서 기출문제도 못 푸는 상태다.
- 훈련용 데이터의 성능만 보면 과적합을 알아낼 수 없다. 그래서 학습에 쓰지 않은 데이터로 성능을 확인하는 아래 방법들을 사용한다.

**`홀드아웃`**

전체 데이터를 **한 번만** 무작위로 나눠, 일부는 훈련용으로 학습하고 나머지는 평가용으로 성능을 확인하는 가장 기본적인 방법이다. (예: 훈련용 70%, 평가용 30%)

- 장점: 간단하고, 학습을 한 번만 하므로 계산이 빠르다. 데이터가 충분히 많을 때 적합하다.
- 단점:
  - 데이터를 어떻게 나누느냐에 따라 성능 평가 결과가 크게 달라질 수 있다. 우연히 쉬운 데이터가 평가용에 몰리면 성능이 실제보다 좋게 나온다.
  - 평가용으로 떼어 낸 데이터는 학습에 사용하지 못하므로, 데이터가 적으면 학습 데이터가 부족해진다.

**`K-Fold 교차검증(cross-validation)`**

전체 데이터를 크기가 같은 $K$개의 그룹(fold)으로 나눈 뒤, 그중 1개를 평가용으로, 나머지 $K-1$개를 훈련용으로 사용한다. 평가용 그룹을 바꿔 가며 이 과정을 $K$번 반복하고, $K$개의 성능을 평균 내어 최종 성능으로 삼는다.

```text
K = 5인 경우 (■: 평가용, □: 훈련용)

1회차: ■ □ □ □ □
2회차: □ ■ □ □ □

```

$$
\text{최종 성능} = \frac{1}{K} \sum_{i=1}^{K} \text{성능}_i
$$

- 모든 데이터가 한 번씩은 평가용으로, $K-1$번은 훈련용으로 사용된다. 그래서 홀드아웃보다 데이터를 나누는 방식의 영향을 덜 받아 성능을 더 안정적으로 평가할 수 있다.
- 단점: 학습을 $K$번 해야 하므로 계산 시간이 오래 걸린다.
- $K$는 보통 5 또는 10을 사용한다.
- $K$를 데이터 개수 $n$과 같게 해서, 매번 1개만 평가용으로 쓰는 방법을 LOOCV(Leave-One-Out Cross Validation)라고 한다. 데이터가 아주 적을 때 사용하지만, 학습을 $n$번 해야 한다.

**`계층별 k-겹 교차 검증(Stratified k-fold cross validation)`**

K-Fold 교차검증과 같지만, 데이터를 $K$개로 나눌 때 **각 그룹의 범주(클래스) 비율이 전체 데이터의 비율과 같도록** 나누는 방법이다.

- 예: 전체 데이터에서 정상 거래가 95%, 사기 거래가 5%라면, 각 그룹도 정상 95%, 사기 5%가 되도록 나눈다.
- 필요한 이유: 범주 비율이 불균형한 데이터를 무작위로 나누면, 어떤 그룹에는 사기 거래가 하나도 없을 수 있다. 그러면 그 그룹으로는 사기 거래를 잘 찾는지 평가할 수 없다.
- 주로 범주 비율이 불균형한 **분류** 문제에서 사용한다.

**`부트스트랩`**

전체 데이터에서 **복원추출**(중복을 허용한 무작위 추출)로 원래 데이터와 같은 크기의 훈련용 데이터를 만들고, 한 번도 뽑히지 않은 데이터를 평가용으로 사용하는 방법이다. 이 과정을 여러 번 반복해 성능을 평균 낸다.

- 예: 데이터가 [1, 2, 3, 4, 5]라면 복원추출로 [1, 1, 3, 4, 4]를 훈련용으로 만들고, 뽑히지 않은 [2, 5]를 평가용으로 쓴다.
- 데이터 개수가 $n$일 때, 특정 데이터가 $n$번의 추출에서 한 번도 뽑히지 않을 확률은 다음과 같다.

  $$
  \left(1 - \frac{1}{n}\right)^n \approx e^{-1} \approx 0.368 \quad (n \text{이 클 때})
  $$
  - 따라서 $n$이 충분히 크면 약 63.2%의 데이터가 훈련용에 한 번 이상 포함되고, 약 36.8%는 평가용이 된다.
  - 이 평가용 데이터를 OOB(Out-Of-Bag) 데이터라고 한다.

- 데이터가 적을 때 유용하다. 같은 데이터를 여러 번 재사용해 많은 훈련용 데이터셋을 만들 수 있기 때문이다.
- 앙상블 모형의 배깅(Bagging)과 랜덤 포레스트도 부트스트랩으로 여러 훈련용 데이터셋을 만들어 사용한다.

**`오버 / 언더샘플링`**

범주(클래스) 비율이 크게 불균형할 때, 비율을 맞추기 위해 데이터 수를 조정하는 방법이다.

- 엄밀히 말하면 성능을 검증하는 방법이 아니라, **불균형 데이터를 학습하기 좋게 만드는 방법**이다. 데이터 분할 단계에서 함께 다루므로 여기에 정리한다.
- 필요한 이유: 정상 99%, 사기 1%인 데이터에서는 모든 거래를 "정상"이라고 예측해도 정확도가 99%다. 모형이 소수 범주를 거의 학습하지 못해, 정작 찾고 싶은 사기 거래를 놓친다.

| 방법                       | 설명                                                                                                                | 장점                      | 단점                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------- | -------------------------------------------------------- |
| 언더샘플링(Under Sampling) | 다수 범주의 데이터를 줄여 소수 범주와 비율을 맞춘다. 예: 정상 9,900건 중 100건만 무작위로 남겨 사기 100건과 맞춘다. | 데이터가 줄어 학습이 빠름 | 버려지는 데이터가 많아 중요한 정보를 잃을 수 있음        |
| 오버샘플링(Over Sampling)  | 소수 범주의 데이터를 늘려 다수 범주와 비율을 맞춘다. 예: 사기 100건을 복제하거나 새로 만들어 9,900건으로 늘린다.    | 정보 손실이 없음          | 같은 데이터가 반복되어 과적합 위험이 있고, 학습이 느려짐 |

- SMOTE(Synthetic Minority Over-sampling Technique): 대표적인 오버샘플링 방법이다. 소수 범주의 데이터와 그 주변의 가까운 소수 범주 데이터(k-최근접 이웃) 사이에 새로운 가상 데이터를 만들어 넣는다. 단순 복제보다 과적합 위험이 적다.
- 주의: 오버/언더샘플링은 데이터를 분할한 **뒤 훈련용 데이터에만** 적용해야 한다. 분할 전에 오버샘플링하면 복제된 같은 데이터가 훈련용과 평가용에 동시에 들어가 성능이 실제보다 좋게 나온다(데이터 누수). 평가용 데이터는 실제 비율 그대로 두어야 현실의 성능을 알 수 있다.
