## 데이터 마이닝 개요

### 데이터마이닝 이해

데이터 마이닝은 대용량 데이터 속에서 숨겨진 규칙, 패턴, 관계 등을 찾아내어 예측하거나 의사결정에 활용하는 것을 목적으로 한다.

- 예: 고객의 구매 이력으로 이탈할 고객을 예측하기, 함께 잘 팔리는 상품 조합 찾기, 비슷한 고객끼리 묶어 마케팅 전략 세우기

**`통계분석과의 차이`**

통계분석은 표본을 통해 의미 있는 정보를 추출하고, 이를 기반으로 의사결정, 연관성 파악, 예측 등의 결과로 이어지도록 하는 일련의 과정을 말한다.

통계학은 표본이 있어야 한다는 것과, 그 표본을 통해 모집단의 특성을 추론한다는 것이 중요하다. 이 통계적 추론은 **추정**(모수의 값을 짐작)과 **가설검정**(가설이 맞는지 판단)으로 이루어진다.

데이터 마이닝은 미리 가설을 세우고 검정하는 과정 없이도, 데이터 속에서 숨겨진 규칙이나 패턴을 찾아 예측이나 설명을 할 수 있다.

- 단, 가설검정을 하지 않는다고 결과를 그대로 믿는 것은 아니다. 찾아낸 모형이 새로운 데이터에서도 맞는지 별도의 데이터(검증·테스트 데이터)로 확인하는 **검증 단계**를 반드시 거친다.

| 구분      | 통계분석                                 | 데이터 마이닝                                  |
| --------- | ---------------------------------------- | ---------------------------------------------- |
| 데이터    | 표본 중심                                | 대용량 데이터(전체 데이터에 가까운 자료)       |
| 접근 방식 | 가설을 세우고 검정한다 (가설 주도)       | 데이터에서 패턴을 찾는다 (데이터 주도)         |
| 주요 관심 | 모집단의 특성 추론, 결과의 통계적 유의성 | 예측 정확도, 활용 가능한 패턴 발견             |
| 검증 방법 | p-값, 신뢰구간                           | 검증·테스트 데이터에서의 성능(정확도, 오차 등) |

데이터 마이닝은 데이터에서 인사이트(예측과 설명)를 얻는 과정으로 이해하면 좋다. 데이터 마이닝의 궁극적인 목적은 인사이트를 얻어 이를 의사결정에 활용하는 데 있다.

### 데이터 마이닝 종류

**`분석 방법에 따른 분류`**

| 분류        | 설명                                                                                                                                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 지도 학습   | 정답(목표변수, 레이블)이 있는 데이터로 학습해, 새로운 데이터의 정답을 예측하는 방법. 목표변수가 연속형이면 회귀, 범주형이면 분류 문제다. 예: 과거 고객의 이탈 여부(정답)를 학습해 신규 고객의 이탈 예측 |
| 비지도 학습 | 정답이 없는 데이터에서 데이터 자체의 구조나 패턴을 찾는 방법. 예: 구매 패턴이 비슷한 고객끼리 묶기(군집), 함께 구매되는 상품 찾기(연관)                                                                 |

**`분석 방법`**

| 구분        | 문제         | 방법 종류                                                                                                                                                                                |
| ----------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 지도학습    | 회귀(연속형) | 선형회귀분석(Linear Regression)<br>Ridge, Lasso(정규화 선형회귀)<br>의사결정나무(회귀트리모형)<br>SVR(Support Vector Regression)<br>신경망 모형                                          |
| 지도학습    | 분류(범주형) | 로지스틱회귀분석<br>의사결정나무(분류트리모형)<br>k-NN(k-최근접 이웃 알고리즘)<br>SVM(Support Vector Machine)<br>나이브 베이즈 분류<br>신경망 모형<br>앙상블 모형<br>LDA(선형 판별 분석) |
| 비지도 학습 | 군집         | 계층적 군집(병합·분할)<br>K-means<br>DBSCAN(밀도 기반 군집)<br>SOM(자기조직화지도)<br>혼합 분포 군집                                                                                     |
| 비지도 학습 | 연관         | Apriori<br>FP-Growth                                                                                                                                                                     |
| 비지도 학습 | 차원축소     | PCA(주성분 분석)<br>SVD(특잇값 분해)<br>MDS(다차원 척도법)                                                                                                                               |

- LDA(선형 판별 분석)는 정답(범주) 정보를 사용하므로 **지도학습**이다. 범주를 가장 잘 구분하는 방향으로 차원을 줄이기 때문에 차원축소에도 쓰이지만, 비지도 학습인 PCA와는 다르다.
- 병합 군집은 계층적 군집의 한 방식(하나씩 합쳐 나가는 상향식)이라 계층적 군집으로 묶었다. 반대로 전체에서 나눠 가는 하향식은 분할 군집이다.
- 의사결정나무, 신경망, k-NN, 앙상블(랜덤 포레스트 등)은 회귀와 분류 모두에 사용할 수 있다.

**`분석 목적에 따른 분류`**

| 분류                      | 설명                                                                                                                                                                   |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 분류(Classification) 분석 | 미리 정해진 범주(정답)가 있는 데이터로 모형을 만들어, 새로운 데이터가 어느 범주에 속할지 예측한다. 지도학습이다. 예: 스팸 메일 분류, 대출 연체 여부 예측               |
| 군집(Clustering) 분석     | 미리 정해진 범주 없이, 비슷한 특성을 가진 객체끼리 그룹으로 묶는다. 비지도학습이다. 그룹의 의미는 분석 후 사람이 해석한다. 예: 구매 패턴에 따른 고객 세분화            |
| 연관(Association) 분석    | 함께 발생하는 사건이나 항목 사이의 규칙("A를 사면 B도 산다")을 찾는다. 비지도학습이다. 장바구니 분석이라고도 한다. 예: 기저귀를 사는 고객이 맥주도 함께 사는 경향 발견 |

- 분류와 군집의 차이: 분류는 범주(정답)가 미리 정해져 있고, 군집은 범주 없이 데이터를 보고 그룹을 만든다.
- ADsP 교재에서는 데이터 마이닝의 기능을 분류(Classification), 추정(Estimation), 예측(Prediction), 연관 분석(Association), 군집(Clustering), 기술(Description)의 6가지로 나누기도 한다. 이 중 분류·추정·예측은 목표변수가 있는 지도학습, 연관·군집·기술은 목표변수가 없는 비지도학습에 해당한다.

### 데이터 마이닝 프로세스

| 단계                         | 설명                                                                                                                                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 목적 정의 단계               | 데이터 마이닝으로 무엇을, 왜 하려는지 분명하게 정한다. 이해관계자가 모두 동의할 수 있는 목적이어야 하며, 이 단계부터 데이터 마이닝 전문가가 참여해 어떤 기법을 쓸지도 미리 정하는 것이 좋다.   |
| 데이터 준비 단계             | 고객 정보, 거래 정보, 상품 정보 등 분석에 필요한 데이터를 수집하고, 데이터 정제(Cleansing)로 품질을 확보한다. 필요하면 외부 데이터를 보강한다. 대용량 데이터라 IT 부서와의 협의가 필요하다.    |
| 데이터 가공 단계             | 목표변수를 정의하고, 수집한 데이터를 분석 기법과 소프트웨어에 적용할 수 있는 형태로 가공한다. 파생변수 생성, 변수 변환, 학습·검증 데이터 분할 등이 이 단계에서 이루어진다.                     |
| 데이터 마이닝 기법 적용 단계 | 목적에 맞는 기법을 선택해 모형을 만든다. 기법과 소프트웨어의 매개변수(파라미터)를 조정해 가며 원하는 결과를 얻는다. 데이터 분석 전문가의 전문성이 필요한 단계다.                               |
| 검증 단계                    | 만들어진 모형의 결과를 검증 데이터나 과거 데이터로 확인하고, 실제 업무에 적용했을 때 얻는 효과(추가 수익, 투자 대비 효과(ROI) 등)를 평가한다. 검증된 모형은 업무에 적용하고 보고서로 정리한다. |

- 각 단계는 한 번에 끝나지 않는다. 검증 결과가 나쁘면 데이터 준비나 가공 단계로 돌아가 다시 진행한다.
