## 다차원 척도법(Multidimensional Scaling, MDS)

다차원 척도법은 객체 간의 근접성(유사성 또는 비유사성)을 저차원 공간에 시각화하는 통계기법이다.

객체들 사이의 유사성 또는 비유사성을 측정하여, 원래의 차원보다 낮은 차원(보통 2차원)의 공간에 각 객체를 점으로 배치한다. 비슷한 객체일수록 가깝게, 다른 객체일수록 멀리 놓인다.

- 예: 도시 간 거리표만 주어졌을 때, 거리 관계를 최대한 유지하도록 도시들을 2차원 평면에 배치하면 지도와 비슷한 그림이 나온다.

다차원 척도법은 데이터를 축소(차원 축소)하고, 데이터 속에 숨어 있는 구조를 눈으로 파악하는 목적으로 사용된다.

- 군집분석과의 차이: 군집분석은 객체를 그룹으로 나누는 기법이고, 다차원 척도법은 객체 사이의 거리 관계를 그림으로 보여주는 기법이다. 다차원 척도법의 결과 그림을 보고 비슷한 객체끼리 모여 있는 그룹을 눈으로 확인할 수는 있지만, 그룹을 직접 나누지는 않는다.
- 주성분 분석과의 차이: 주성분 분석은 변수들의 분산(정보)을 최대한 보존하는 방향으로 차원을 줄이고, 다차원 척도법은 객체 사이의 거리를 최대한 보존하는 방향으로 차원을 줄인다.

객체들간의 거리는 일반적으로 유클리디안 거리행렬을 사용하여 계산한다.

$$
d_{ij} = \sqrt{\sum_{k=1}^{p}(x_{ik} - x_{jk})^2}
$$

- $d_{ij}$: 객체 $i$와 $j$ 사이의 거리, $x_{ik}$: 객체 $i$의 $k$번째 변수 값, $p$: 변수의 수

### 다차원 척도법의 측도

개체의 실제 거리와 모형에 의해 추정된 거리 사이의 적합도를 측정하기 위해 stress 척도를 사용한다. ($d_{ij}$: 객체 $i$와 $j$의 실제 거리, $\hat{d}_{ij}$: 저차원 공간에서 추정된 거리)

$$
stress = \sqrt{\frac{\sum_{i<j}(d_{ij} - \hat{d}_{ij})^2}{\sum_{i<j} d_{ij}^2}}
$$

- 실제 거리와 추정된 거리의 차이를 제곱해 더한 값을, 실제 거리의 제곱합으로 나눠 크기를 맞춘 것이다. 두 거리가 완전히 같으면 0이 된다.

$stress$ 값은 0 ~ 1 사이의 값을 가지며 값이 낮을수록 적합도가 높다고 평가한다. 일반적으로 0.05 이내의 값이면 적합도가 좋다고 판단하며, 0.15 이상이면 적합도가 나쁘다고 판단한다.

| stress 값   | 적합도    |
| ----------- | --------- |
| 0           | 완벽      |
| 0 ~ 0.05    | 매우 좋음 |
| 0.05 ~ 0.10 | 만족      |
| 0.10 ~ 0.15 | 보통      |
| 0.15 이상   | 나쁨      |

- 크루스칼(Kruskal)이 처음 제안한 기준은 0.2 나쁨, 0.1 보통, 0.05 좋음, 0.025 매우 좋음으로 조금 다르다.
- stress가 크면 차원 수를 늘려(예: 2차원 → 3차원) 다시 적합해 본다. 차원이 높을수록 stress는 작아지지만 시각화와 해석은 어려워진다.

### 다차원 척도법 종류

| 구분         | 척도               | 설명                                                                                                                                                                  |
| ------------ | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 계량적 MDS   | 구간척도, 비율척도 | 객체 간 거리를 실제 수치 그대로 사용해, 저차원 공간에서도 거리의 크기가 최대한 유지되도록 배치한다. 유클리디안 거리를 쓰는 고전적 MDS가 대표적이다. (R: `cmdscale()`) |
| 비계량적 MDS | 순서척도           | 거리의 실제 값이 아니라 순서(순위)만 유지되도록 배치한다. 선호도 순위처럼 값의 크기는 의미가 없고 순서만 의미 있는 자료에 사용한다. (R: `MASS` 패키지의 `isoMDS()`)   |

- 예: "A와 B는 3.2만큼 다르다"처럼 차이의 크기를 숫자로 잴 수 있으면 계량적 MDS, "A와 B가 A와 C보다 더 비슷하다"처럼 순서만 알 수 있으면 비계량적 MDS를 사용한다.

## 시계열 분석

시계열 분석은 일정 시간 간격으로 기록된 자료(시계열 자료)의 특성을 파악하고 미래를 예측하는 분석방법이다.

- 예: 일별 주가, 월별 매출, 시간별 기온, 일별 광고 클릭 수

### 시계열 자료의 자기상관성

주식이나 기온 등의 시계열 자료들은 자기상관성(Autocorrelation)을 가지고 있다. 즉, **하나의 변수가 자기 자신의 과거 값과** 상관관계를 가진다.

- 서로 다른 두 변수 사이의 상관관계가 아니라, 같은 변수의 현재 값 $Y_t$와 과거 값 $Y_{t-k}$ 사이의 상관관계라는 점이 핵심이다.
- 예: 오늘 기온이 높으면 내일 기온도 높을 가능성이 크다. 오늘 기온과 어제 기온은 서로 독립이 아니다.

회귀분석에서는 하나의 잔차항이 이웃한 잔차항과 일정한 관련이 있는 것을 자기상관이라고 한다. 시계열 자료로 회귀분석을 하면 이런 잔차의 자기상관이 자주 나타나며, 더빈-왓슨 검정으로 확인한다.

**`공분산과 시계열 분석`**

공분산이란 분산의 개념을 두 확률변수로 확장한 것으로, 두 변수가 **함께 변하는 방향과 정도**를 나타낸다.

- 공분산 > 0: 한 변수가 커질 때 다른 변수도 커지는 경향
- 공분산 < 0: 한 변수가 커질 때 다른 변수는 작아지는 경향
- 공분산 = 0: 선형 관계가 없음

시계열에서는 같은 변수의 현재 값과 $k$ 시점 전 값 사이의 공분산을 계산하며, 이를 **자기공분산**(Autocovariance)이라고 한다. ($\mu$: 시계열의 평균, $k$: 시차(lag))

$$
\gamma_k = Cov(Y_t, Y_{t-k}) = E[(Y_t - \mu)(Y_{t-k} - \mu)]
$$

- $k = 0$이면 자기 자신과의 공분산이므로 분산과 같다. ($\gamma_0 = Var(Y_t)$)
- 시계열 자료는 일반적으로 자기상관성을 가지므로, 시차 $k \ge 1$에서의 자기공분산이 0이 아니다.
- 공분산은 단위에 따라 크기가 달라져 비교가 어렵기 때문에, 분산으로 나눠 $-1$ ~ $1$ 사이로 표준화한 자기상관계수(ACF)를 주로 사용한다.

### 시계열 분석의 자료

대부분의 시계열 모형(AR, MA, ARMA 등)은 자료가 **정상성**(Stationarity)을 만족한다고 가정한다. 하지만 실제 시계열 자료는 대부분 비정상성이므로, 이를 정상성 시계열 자료로 변환하는 과정이 필요하다.

| 구분                 | 설명                                                                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 정상성 시계열 자료   | 시점이 바뀌어도 평균, 분산, 공분산 같은 통계적 성질이 변하지 않는 자료. 일정한 수준을 중심으로 비슷한 폭으로 오르내린다.                 |
| 비정상성 시계열 자료 | 시간에 따라 통계적 성질이 변하는 자료. 추세(계속 증가·감소), 계절성(주기적 반복), 시간에 따라 커지는 변동폭 등이 있으면 비정상성 자료다. |

- 정상성이 필요한 이유: 시간에 따라 성질이 계속 바뀌면, 과거 데이터로 찾은 패턴이 미래에도 유지된다고 볼 수 없어 예측 모형을 세우기 어렵다.

**`시계열 자료의 정상성 조건`**

| 조건                     | 설명                                                                                                                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 일정한 평균              | 모든 시점에서 평균이 같다. ($E(Y_t) = \mu$)                                                                                                                                         |
| 일정한 분산              | 모든 시점에서 분산이 같다. ($Var(Y_t) = \sigma^2$)                                                                                                                                  |
| 시차에만 의존하는 공분산 | 두 시점 사이의 공분산은 **어느 시점인지**($t$)가 아니라 **얼마나 떨어져 있는지**(시차 $k$)에만 의존한다. 예: 1월과 3월, 6월과 8월의 공분산은 같다. ($Cov(Y_t, Y_{t-k}) = \gamma_k$) |

**`비정상성 자료를 정상성 자료로 바꾸는 방법`**

| 문제                 | 처리 방법                                                                       |
| -------------------- | ------------------------------------------------------------------------------- |
| 평균이 일정하지 않음 | 차분(Differencing): 현재 값에서 이전 값을 뺀다. ($\nabla Y_t = Y_t - Y_{t-1}$)  |
| 계절성이 있음        | 계절 차분: 현재 값에서 한 주기 전 값을 뺀다. (예: 월별 자료면 $Y_t - Y_{t-12}$) |
| 분산이 일정하지 않음 | 변환(Transformation): 로그 변환, 제곱근 변환 등으로 변동폭을 일정하게 만든다.   |

### 자기상관계수

**`자기상관계수(ACF: Autocorrelation Function)`**

자기상관함수는 현재 시점의 값 $Y_t$와 $k$ 시점 전의 값 $Y_{t-k}$ 사이의 상관계수를 시차 $k$에 따라 나타낸 함수다.

$$
\rho_k = \frac{Cov(Y_t, Y_{t-k})}{Var(Y_t)} = \frac{\gamma_k}{\gamma_0}
$$

- 중요한 것은 특정 시점이 아니라 **시차**에 따른 상관관계라는 점이다. 정상성 조건에서 공분산이 시차에만 의존하므로, 자기상관계수도 시차 $k$만의 함수가 된다.
- $\rho_0 = 1$이며, 값은 $-1$ ~ $1$ 사이다.
- 시차별 자기상관계수를 막대그래프로 그린 것을 **코렐로그램**(Correlogram)이라고 한다.

자기상관함수는 시계열 자료가 **무작위성**을 띠는지 확인하는 데 사용한다.

- 모든 시차에서 자기상관계수가 0에 가깝다면, 과거 값과 현재 값이 관련이 없는 무작위 자료(백색잡음, White Noise)다. 과거로부터 배울 패턴이 없으므로 평균 이상의 예측은 어렵다.
- 반대로 자기상관이 있다면(무작위성을 띠지 않는다면), 과거 값의 패턴을 이용해 미래 값을 예측할 수 있다.
- 자기상관계수가 아주 천천히 줄어든다면 추세가 있는 비정상성 자료일 가능성이 크므로 차분이 필요하다.

**`부분자기상관계수(PACF: Partial Autocorrelation Function)`**

부분자기상관함수는 $Y_t$와 $Y_{t-k}$ 사이의 상관관계에서, 그 사이에 있는 시점들($Y_{t-1}, \dots, Y_{t-k+1}$)의 영향을 제거한 상관관계를 나타낸 함수다.

- 예: 오늘 기온과 이틀 전 기온의 상관관계가 높게 나왔더라도, 사실은 "이틀 전 → 어제 → 오늘"로 이어진 간접적인 영향일 수 있다. 부분자기상관계수는 어제 기온의 영향을 제거하고 오늘과 이틀 전 기온 사이의 직접적인 관계만 본다.

이 개념은 일반적인 **부분상관**(Partial Correlation)을 시계열에 적용한 것이다. 부분상관은 두 변수의 관계를 볼 때, 둘 모두에 영향을 주는 다른 변수의 영향을 제외하고 둘 사이의 관계만 보는 것이다.

예를 들어 교회가 많을수록 범죄 발생률이 높다는 연구가 있다고 가정하자.

- 교회가 많다는 것은 인구수가 많다는 것이고, 인구가 많으면 범죄도 많이 발생한다.
- 이 때 둘 모두에 영향을 주는 '인구'라는 요소를 통제하면, 교회 수와 범죄 발생률 사이의 상관관계는 거의 사라질 수 있다.
- 시계열에서는 이 '인구' 역할을 사이에 있는 시점들의 값이 한다.

**`ACF, PACF로 모형 식별하기`**

ACF와 PACF 그래프의 모양을 보고 어떤 시계열 모형이 적합한지 판단한다. (절단: 특정 시차 이후 갑자기 0에 가까워짐, 감소: 지수적으로 또는 사인 곡선 형태로 천천히 0에 가까워짐)

| 모형         | ACF                 | PACF                |
| ------------ | ------------------- | ------------------- |
| AR($p$)      | 천천히 감소         | $p+1$ 시차부터 절단 |
| MA($q$)      | $q+1$ 시차부터 절단 | 천천히 감소         |
| ARMA($p, q$) | 천천히 감소         | 천천히 감소         |

- 예: PACF가 시차 2 이후로 0에 가까워지고 ACF는 천천히 줄어든다면 AR(2) 모형을 고려한다.

### 시계열 분석 기법

| 기법       | 설명                                                                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 이동평균법 | 최근 일정 기간($m$)의 관측값을 평균 내어 다음 시점을 예측하거나 추세를 파악하는 방법. 기간 안의 모든 관측값에 **같은 가중치**를 준다.                                      |
| 지수평활법 | 모든 과거 관측값을 사용하되, **최근 관측값일수록 더 큰 가중치**를 주고 과거로 갈수록 가중치를 지수적으로 줄여 평균을 내는 방법. 가중치는 지수평활계수 $\alpha$로 조절한다. |

**`이동평균법`**

$$
\hat{Y}_{t+1} = \frac{Y_t + Y_{t-1} + \cdots + Y_{t-m+1}}{m}
$$

- 예: 3개월 이동평균으로 4월 매출을 예측하면 (1월 + 2월 + 3월) / 3, 5월은 (2월 + 3월 + 4월) / 3이다. 기간이 한 칸씩 이동하므로 이동평균이라고 한다.
- 불규칙변동(우연한 오르내림)이나 계절변동을 제거해 추세를 파악하는 용도로도 사용한다.
- $m$이 클수록 그래프가 더 매끄러워진다(평활 효과가 크다). 대신 최근 변화에 늦게 반응한다.
- 불규칙변동이 심하면 큰 $m$, 뚜렷한 추세가 있거나 불규칙변동이 작으면 작은 $m$을 사용한다.
- 시계열 모형의 MA(이동평균 모형)와는 다른 개념이다. MA 모형은 과거 관측값이 아니라 과거 **오차항**의 조합으로 현재 값을 설명한다.

**`지수평활법`**

$$
S_t = \alpha Y_t + (1 - \alpha) S_{t-1} \quad (0 < \alpha < 1)
$$

- $S_t$: $t$ 시점의 평활값(다음 시점의 예측값), $Y_t$: $t$ 시점의 관측값, $\alpha$: 지수평활계수
- 식을 풀어 쓰면 가중치가 $\alpha, \alpha(1-\alpha), \alpha(1-\alpha)^2, \dots$로 과거로 갈수록 지수적으로 작아진다.

  $$
  S_t = \alpha Y_t + \alpha(1-\alpha) Y_{t-1} + \alpha(1-\alpha)^2 Y_{t-2} + \cdots
  $$

- $\alpha$가 클수록 최근 값에 민감하게 반응하고, 작을수록 그래프가 매끄러워진다.
  - 불규칙변동이 큰 시계열에는 작은 $\alpha$, 불규칙변동이 작은 시계열에는 큰 $\alpha$를 사용한다.
  - 실제로는 여러 $\alpha$로 예측해 본 뒤 예측 오차가 가장 작은 값을 선택한다.
- 예: $\alpha = 0.3$, 전 시점 예측값 $S_{t-1} = 100$, 이번 관측값 $Y_t = 120$이면 $S_t = 0.3 \times 120 + 0.7 \times 100 = 106$이다.
- 단순 지수평활법은 추세나 계절변동이 있는 시계열에는 적합하지 않다. 추세가 있으면 홀트(Holt) 방법, 추세와 계절성이 모두 있으면 홀트-윈터스(Holt-Winters) 방법을 사용한다.
